# 模板 A · 文章页（解决「内容量不够、易读性差」）

## 为什么精简版会变薄

Stitch 把提示词里的文字当成**「描述你想要什么设计」**，不当成**「这是要排版的内容」**。
所以你贴一篇 3000 字的 md 进去，它读完之后自己总结出七八条要点，做成一屏漂亮的卡片墙——
UI 很好，内容掉了 80%。这不是它做得不好，是任务下错了。

**修法只有一条**：明确告诉它文字是**成品**，只能排版，不能改写、缩短、省略；
放不下就改版式，不许删字。下面的模板第一段就在做这件事。

## 还要做的两件事

1. **一次只喂一课，而且要分段喂。**一课 3000–5000 字超出它一次能认真处理的量。
   按下面的「区块清单」拆成 3–4 次对话，每次做一个区块，最后让它拼版。
2. **正文用衬线体、行长 710px、行高 1.85。**Stitch 默认给无衬线 + 满宽 + 行高 1.5，
   这是「易读性差」的直接原因。契约里已经写死了，但每次都要附参考图复核。

## 可直接粘贴的模板

> 用法：先粘 `00-style-contract.md` 的契约文本，空一行，再粘下面这段，
> 然后把 `{{...}}` 换成真实内容，并附上 `reference/28-scenario-lab.png`。

```text
【任务】
为这门课的第 {{课号}} 课「{{课程标题}}」排一个文章区块。

【最重要的一条】
下面〈正文〉里的每一个字都是最终稿，由作者写定。
你的工作是**排版**，不是写作：
  - 不许改写、精简、总结、换措辞、翻译
  - 不许省略任何一句，也不许把段落合并成要点列表
  - 排不下就调整版式（分栏、留白、字号），不许删字
  - 需要小标题时，只能从正文里已有的句子中提取，不许新写

【阅读体验硬指标】
  - 正文列宽固定 710px 居中，不要满宽
  - 正文用衬线字体，16px，行高 1.85，段间距 20px
  - 每屏至少有一次视觉换气：代码块 / 引述 / 要点卡 / 分隔线
  - 中英文之间留 0.25em 间隙；行内代码用等宽字体 + 浅底 + 2px 圆角
  - 段落之间不要用卡片包起来——正文就是正文，只有特殊区块才进卡片

【这个区块的结构】
{{从下面「区块清单」里挑一种，把它的说明粘过来}}

【正文】
{{把 md 里对应这一段的原文整段粘进来，保留 Markdown 标记}}

【输出】
桌面 1440px 和移动 390px 各一版。
```

## 区块清单（一课拆成这几次对话）

| 次序 | 区块 | 给 Stitch 的说明 |
| --- | --- | --- |
| 1 | **课头** | 上方一行等宽小字「LESSON {{n}} · {{单元名}}」；下面是两行的大标题，第二行换行处由我指定；再下面一段导语（次要文字色）；最后一行三个小徽章：预计时长 / 是否需要 API / 承接第几课。整块左对齐，不要居中，不要配图。 |
| 2 | **正文段落组** | 每个段落组是：一行等幅小标签（大写字母间距 0.12em，次要色）+ 一个 h2 + 若干正文段。小标签和 h2 之间距离要近，和上一组之间距离要远——靠间距而不是分隔线来分组。 |
| 3 | **代码块** | 深色终端底 #13221b，圆角 8px，等宽字体 13px，行高 1.7，不要行号，不要窗口红绿灯装饰，不要复制按钮。上方可以有一行说明性 caption（次要色小字）。代码在小屏可横向滚动，但**整页不许出现横向滚动条**。 |
| 4 | **提示框 / 误区卡 / 要点卡** | 三种：①提示框（浅绿底 #e8efe9，左侧 3px 深绿竖条，标题加粗）；②误区卡（列表，每条左边是被划掉的错误说法，右边是一枚珊瑚色小徽章写结论，下面是解释）；③要点卡（编号 1/2/3，柠檬绿数字圆角方块 + 一句话）。 |
| 5 | **拼版** | 把前面几次的产出按顺序拼成完整一页，检查：所有区块左右边缘对齐同一条 710px 主栏；只有互动实验可以到 920px。 |

## 拿到产出之后怎么用

Stitch 导出的是 HTML + Tailwind。**不要整页搬进仓库**，本站是原生 CSS 变量，不是 Tailwind。
正确做法：

1. 只看它的**版式决策**——间距、字号阶梯、分栏、区块顺序。
2. 把这些决策改写成 `apps/web/src/app/globals.css` 里的规则，颜色一律用已有的 `var(--…)`。
3. 文字与结构继续用 `apps/web/src/components/article-kit.tsx` 里的
   `Prose` / `CodeBlock` / `Callout` / `Misconceptions` / `Takeaways`——
   这些组件已经接了术语悬停（`auto-term.tsx`），换成裸 HTML 会把这个能力弄丢。
