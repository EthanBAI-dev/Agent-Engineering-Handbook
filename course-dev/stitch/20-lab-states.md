# 模板 B · 互动实验（Stitch 只能出「状态图」，不能出交互）

## 先说清楚它能做什么

Stitch 产出的是**静态 HTML**。它做不出状态机——点击不会真的改变数据，
条件分支、localStorage、通过判定全都不会有。

所以不要让它「做一个互动」，要让它**把同一个组件的 N 个状态各画一张**，
然后把状态之间的切换留给代码。本仓库已经有现成的状态机了：

- `apps/web/src/components/lab-kit.tsx` — `ScenarioLab` / `ClassifyLab` / `OrderLab`
- 每个实验只需要提供**数据**和一个**纯函数** `compute(state) → outcome`

所以 Stitch 的工作范围很明确：**只换皮，不换骨。**
它的产出会变成 `globals.css` 里 `.kit-*` 那几十行规则的新版本，一次改完 31 课全部生效。

## 三种骨架，各自要几张状态图

| 骨架 | 用在 | 要 Stitch 出的状态 |
| --- | --- | --- |
| `ScenarioLab` | 拨开关看确定性结果（最常用，20+ 课） | ①初始态 ②改了开关但没达成 ③达成态（柠檬绿通过条） ④结果里有失败行（珊瑚色） |
| `ClassifyLab` | 给每个条目选一个归属 | ①全未答 ②答对一部分（对错各有样式） ③全对 |
| `OrderLab` | 把条目排成正确顺序 | ①乱序 ②部分位置正确 ③全对 |

## 可直接粘贴的模板

> 先粘契约文本，再粘这段，附 `reference/28-scenario-lab.png` 和 `reference/30-classify-lab.png`。
> `out/` 目录里每个互动都已经生成好了填完的版本，可以直接拿。

```text
【任务】
为第 {{课号}} 课的互动实验「{{实验标题}}」出**状态图**，不要做交互。
同一个组件，画 {{N}} 个状态，纵向排列，每个状态上方标一行小字说明它是什么状态。

【这个实验在教什么】
{{一句话}}

【组件结构 · 从上到下】
1. 工具条：左边一行等宽小字「INTERACTIVE {{课号}}」+ 下面一行组件标题；
   右边一枚状态药丸（未达成：浅底描边；达成：柠檬绿 #bafa4b 实底 + #4d7100 字）
2. 控件区：{{控件清单，见下}}
3. 结果区：左右两栏等宽
   左栏「{{结果栏标题}}」：一个定义列表，每行是「标签 — 值」，
        标签用次要色 13px，值用等宽加粗 13px 右对齐；
        值可以是绿（好）、珊瑚（坏）、灰（中性）三种色调；
        行与行之间用虚线分隔；**标签不许被挤成竖排单字**
   右栏「过程说明」：1–3 段说明文字，其中「好」的一段是浅绿底圆角块，
        「坏」的一段是珊瑚浅底圆角块，中性的一段是纯文字
4. 判定条：整宽一条，未达成时是浅底 + 次要色文字；达成时是柠檬绿实底 + 深色文字 + 末尾一个 ✓
5. 脚注：一行 12px 次要色小字，说明数据来自真实运行
6. 一个折叠的「展开代码」，收起时只是一行带三角的小标题

【控件清单】
{{逐条列出，每条写明：标签文字 / 类型（分段按钮 or 开关 or 滑杆）/ 选项文字}}
分段按钮：一组并排的方角按钮（4px 圆角），选中项柠檬绿实底 + 2px 3px 0 0 硬投影
开关：一个方形复选框 + 一行说明文字，整体包在一个描边小卡里，打开时描边变深绿
滑杆：一条细轨道 + 方形滑块，右侧一个等宽数值

【硬约束】
  - 控件区左侧是标签列，右侧是控件列，两列在 720px 以下改为上下堆叠
  - 结果区左右两栏在 720px 以下改为上下堆叠
  - 任何宽度下都不许出现整页横向滚动
  - 这个区块是全页唯一允许加宽到 920px 的部分

【输出】
桌面 1440px 和移动 390px 各一版。
```

## 拿到产出之后怎么用

改 `apps/web/src/app/globals.css` 里这几组类，31 课一次全生效：

```
.kit-lab / .lab-toolbar / .status-pill      工具条与状态药丸
.kit-controls / .kit-control                控件区两列布局
.kit-segmented / .kit-switch / .kit-slider  三种控件
.kit-outcome / .kit-rows / .kit-log         结果区左右两栏
.kit-verdict / .simulation-note             判定条与脚注
.kit-classify / .kit-order                  另外两种骨架
```

**不要改 `lab-kit.tsx` 的 DOM 结构**——31 课的实验都挂在这套类名上，
改结构等于同时改 31 课，而且 Playwright 的验证脚本也是按这些类名找元素的。
如果 Stitch 的设计确实需要新节点，先说清楚要加哪一个，再统一加。
