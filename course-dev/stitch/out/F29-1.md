```text
## 归属表不能放进 State

`OWNERSHIP` 是服务端的数据，不是图的 State。

放进 State 的东西，第 17 课的 `update_state` 就能改。审批界面上多一个字段，就成了越权的入口——而那个界面本来是用来提升安全性的。

**谁拥有什么，只能由服务端单独保管。**

【画什么】
上栏没有归属检查——bob 拿着 `t_alice` 直接取到了 alice 的消息； 下栏加了归属检查——服务端的归属表挡在数据库之前，两种失败都回同一句「找不到这个会话」。

【必须标注】
归属表标「来自服务端会话，不来自请求参数」；两种拒绝回同一句话。

【不要出现】
把 `thread_id` 画成一把钥匙——它只是一个编号。

【替代文本（原样写进 <title> 与 <desc>）】
没有归属检查时凭编号就能读到别人的会话，加上服务端归属表后越权和不存在都返回同一句话。

【硬约束】
  - viewBox="0 0 720 H"，width="100%" height="auto"，不写固定 px 宽度
  - 颜色写成带兜底值的 CSS 变量：
      --ink #17231f  --muted #68736d  --card #fffdf7  --line #c9cfc7
      --lime #bafa4b（配 --on-lime #4d7100）  --green #355e48  --tertiary #9c432c
  - 圆角 rx="8"（小徽章 rx="2"）
  - 不用滤镜／渐变／blur；要立体感就用 2px 3px 的实心偏移矩形
  - font-family="var(--font-ui)"，正文 13px、标签 11px、标题 15px
  - 箭头用统一的 <marker>
  - 中文直接写在 <text> 里，不要转曲线

【自检】
  - 「必须标注」的每一条都能在 <text> 里找到
  - 「不要出现」的每一条确实没有出现
```
