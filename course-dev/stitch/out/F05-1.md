## 路线 A（推荐）· 让能写代码的模型直接产出 SVG

把下面整段贴给 Claude / Codex：

```text
【任务】写一个 SVG，落到 apps/web/public/assets/lessons/05-blueprint.svg

【这张图在讲什么】
## 互动挑战：把打乱的卡片排回去

网页会给出这些卡片：

    model
    safe_tools
    approval
    risky_tools
    report
    checkpointer
    thread_id

你的任务是把它们放进正确位置，并满足五个条件：

1. `safe_tools` 执行后回到 model
2. 删除动作先进入 approval
3. approval 拒绝后不能进入 risky_tools
4. 图带有 checkpointer
5. 暂停与恢复使用同一个 `thread_id`

挑战通过的标准不是画得和示例一模一样，而是这五条约束全部成立。

【画什么】
一张图里同时出现四样东西：`model ⇄ tools` 闭环、危险工具前的 approval 暂停点、 贯穿全图的 checkpointer 底纹、以及拒绝后的安全结束路径。

【必须标注】
四个部件各自来自第几课；同一个 `thread_id` 贯穿；拒绝路径不碰任何副作用。

【不要出现】
本课没讲过的部件（重试、并行、子图）——蓝图要和课程进度一致。

【替代文本（原样写进 <title> 与 <desc>）】
完整 Agent 蓝图包含模型与工具的闭环、危险动作前的人工审批、贯穿全程的检查点，以及拒绝后的安全结束路径。

【硬约束】
  - viewBox="0 0 720 H"，width="100%" height="auto"，不写固定 px 宽度
  - 颜色写成带兜底值的 CSS 变量：
      --ink #17231f  --muted #68736d  --card #fffdf7  --line #c9cfc7
      --lime #bafa4b（配 --on-lime #4d7100）  --green #355e48  --tertiary #9c432c
  - 圆角 rx="8"（小徽章 rx="2"）
  - 不用滤镜／渐变／blur；要立体感就用 2px 3px 的实心偏移矩形
  - font-family="var(--font-ui)"，正文 13px、标签 11px、标题 15px
  - 箭头用统一的 <marker>
  - 中文直接写在 <text> 里，不要转曲线

【自检】
  - 「必须标注」的每一条都能在 <text> 里找到
  - 「不要出现」的每一条确实没有出现
```
