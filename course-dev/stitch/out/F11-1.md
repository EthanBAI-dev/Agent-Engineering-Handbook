## 路线 A（推荐）· 让能写代码的模型直接产出 SVG

把下面整段贴给 Claude / Codex：

```text
【任务】写一个 SVG，落到 apps/web/public/assets/lessons/11-two-guards.svg

【这张图在讲什么】
## 三种情况的实跑结果

**正常分类**：

    这个我想退掉       → route=refund    已为你创建退款单。
    我的包裹到哪了      → route=shipping  你的包裹在配送中。
    我要投诉         → route=human     已转接人工客服。

**模型给了一个不存在的类别**：

    模型原始输出 raw_route = 'REFUND_NOW'
    白名单校验后 route     = 'human'
    最终回答               = 已转接人工客服。

**模型完全没走结构化输出**：

    模型原始输出 raw_route = '我觉得应该给他退款吧'
    白名单校验后 route     = 'human'
    最终回答               = 已转接人工客服。

后两种情况都没有崩，也没有走错分支。

【画什么】
模型输出经过两道关卡才进入分支。第一道「结构化输出」标「更可能对」， 第二道「白名单校验」标「保证对」。三条示例输入从上方进入，非法的两条在第二道被拨到兜底分支。

【必须标注】
两道关卡的性质差别；兜底分支标「最安全的那条」。

【不要出现】
把第一道画成能单独挡住——那正是本课要纠正的。

【替代文本（原样写进 <title> 与 <desc>）】
模型的分类结果先经过结构化输出，再经过白名单校验，非法值一律落到最安全的兜底分支。

【硬约束】
  - viewBox="0 0 720 H"，width="100%" height="auto"，不写固定 px 宽度
  - 颜色写成带兜底值的 CSS 变量：
      --ink #17231f  --muted #68736d  --card #fffdf7  --line #c9cfc7
      --lime #bafa4b（配 --on-lime #4d7100）  --green #355e48  --tertiary #9c432c
  - 圆角 rx="8"（小徽章 rx="2"）
  - 不用滤镜／渐变／blur；要立体感就用 2px 3px 的实心偏移矩形
  - font-family="var(--font-ui)"，正文 13px、标签 11px、标题 15px
  - 箭头用统一的 <marker>
  - 中文直接写在 <text> 里，不要转曲线

【自检】
  - 「必须标注」的每一条都能在 <text> 里找到
  - 「不要出现」的每一条确实没有出现
```
