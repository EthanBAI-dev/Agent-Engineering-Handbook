```text
## 反面示范：把决定权交给模型

很多 RAG 实现是这样的——不管检索到没有，都把上下文交给模型，并在提示词里写「如果资料不足请说不知道」。

实跑结果：

    问：公司几点下班？
    答：公司一般下午六点下班。
    依据：（无）

语气笃定，没有出处，内容是编的。**用户没有任何办法分辨这一句和上一句的区别。**

第 06 课那条边界在这里第三次出现：提示词是建议，代码是约束。「不知道就说不知道」写在提示词里是劝阻，写成条件边才是阻止。

【画什么】
`retrieve` 之后一个条件边分成两条：命中走 answer（模型图标在这条路上）， 落空走 refuse（这条路上**没有**模型图标）。answer 的输出带一张引用卡片，refuse 的输出没有。

【必须标注】
refuse 那条标「模型没有被调用，也就没有机会编」。

【不要出现】
在 refuse 那条路上画模型——那正是反面示范的做法。

【替代文本（原样写进 <title> 与 <desc>）】
检索命中才交给模型回答并附引用，检索落空直接走拒绝分支，模型不参与。

【硬约束】
  - viewBox="0 0 720 H"，width="100%" height="auto"，不写固定 px 宽度
  - 颜色写成带兜底值的 CSS 变量：
      --ink #17231f  --muted #68736d  --card #fffdf7  --line #c9cfc7
      --lime #bafa4b（配 --on-lime #4d7100）  --green #355e48  --tertiary #9c432c
  - 圆角 rx="8"（小徽章 rx="2"）
  - 不用滤镜／渐变／blur；要立体感就用 2px 3px 的实心偏移矩形
  - font-family="var(--font-ui)"，正文 13px、标签 11px、标题 15px
  - 箭头用统一的 <marker>
  - 中文直接写在 <text> 里，不要转曲线

【自检】
  - 「必须标注」的每一条都能在 <text> 里找到
  - 「不要出现」的每一条确实没有出现
```
