```text
## 这和第 17 课的区别

第 17 课已经用过一次分叉——退回 `propose` 之前改参数。区别在于目的：

| | 目的 | 谁在操作 |
| --- | --- | --- |
| 第 17 课 | 修正一个正在进行的任务 | 审批的人，在界面上 |
| 第 18 课 | 理解 Agent 为什么这样做 | 开发者，在调试时 |

同一个机制，两种用法。

【画什么】
一条时间轴上四个快照点，每个点标注当时的 `values` 和 `next`。 从中间一点拉出一条分叉线，末端是改了输入之后的另一条完整路径；原路径保持完整。

【必须标注】
每个点的 `next`（这是「能继续执行」的依据）；分叉后两条路都还在。

【不要出现】
把分叉画成覆盖原路径——旧快照不会消失。

【替代文本（原样写进 <title> 与 <desc>）】
每个检查点都记录了当时的状态和下一步要跑的节点，从中间分叉会产生新分支而不覆盖原路径。

【硬约束】
  - viewBox="0 0 720 H"，width="100%" height="auto"，不写固定 px 宽度
  - 颜色写成带兜底值的 CSS 变量：
      --ink #17231f  --muted #68736d  --card #fffdf7  --line #c9cfc7
      --lime #bafa4b（配 --on-lime #4d7100）  --green #355e48  --tertiary #9c432c
  - 圆角 rx="8"（小徽章 rx="2"）
  - 不用滤镜／渐变／blur；要立体感就用 2px 3px 的实心偏移矩形
  - font-family="var(--font-ui)"，正文 13px、标签 11px、标题 15px
  - 箭头用统一的 <marker>
  - 中文直接写在 <text> 里，不要转曲线

【自检】
  - 「必须标注」的每一条都能在 <text> 里找到
  - 「不要出现」的每一条确实没有出现
```
