# F27-1｜总分会掩盖回归

- 形式：逐例对照图 · `assets/lessons/27-per-case-diff.svg`
- 目标文件：`assets/lessons/27-per-case-diff.svg`

## 路线 A（推荐）· 让能写代码的模型直接产出 SVG

把下面整段贴给 Claude / Codex：

```text
【任务】写一个 SVG，落到 apps/web/public/assets/lessons/27-per-case-diff.svg

【这张图在讲什么】
## 最小可行的可观测：三样东西

每次运行记下：

1. **走了哪些节点** —— 区分「答错了」和「本该拒绝却回答了」
2. **每步花了多久** —— 找出是哪一步慢
3. **模型调用了几次** —— 对应第 10 课的成本

这三样不需要任何工具，往 State 里加一个 `trace` 字段就有了。等规模上来了再换成专门的追踪平台，思路是一样的。

【画什么】
三列（v1/v2/v3）× 五行（c1–c5）的方格，通过打勾、不通过打叉。 右侧两行文字：`v1→v2 修好 c5`、`v2→v3 弄坏 c5`。

【必须标注】
总分那一行；以及「总分一样时逐例仍可能有得有失」。

【不要出现】
只画折线图——本课的要点恰恰是总分不够用。

【替代文本（原样写进 <title> 与 <desc>）】
逐例对照能看出每次改动修好了哪条、弄坏了哪条，而总分会把两者抵消掉。

【硬约束】
  - viewBox="0 0 720 H"，width="100%" height="auto"，不写固定 px 宽度
  - 颜色写成带兜底值的 CSS 变量：
      --ink #17231f  --muted #68736d  --card #fffdf7  --line #c9cfc7
      --lime #bafa4b（配 --on-lime #4d7100）  --green #355e48  --tertiary #9c432c
  - 圆角 rx="8"（小徽章 rx="2"）
  - 不用滤镜／渐变／blur；要立体感就用 2px 3px 的实心偏移矩形
  - font-family="var(--font-ui)"，正文 13px、标签 11px、标题 15px
  - 箭头用统一的 <marker>
  - 中文直接写在 <text> 里，不要转曲线

【自检】
  - 「必须标注」的每一条都能在 <text> 里找到
  - 「不要出现」的每一条确实没有出现
```
