## 路线 A（推荐）· 让能写代码的模型直接产出 SVG

把下面整段贴给 Claude / Codex：

```text
【任务】写一个 SVG，落到 apps/web/public/assets/lessons/01-state-fields.svg

【这张图在讲什么】
## State：所有节点共享的现场

先看这份 State：

    class State(TypedDict):
        topic: str
        count: int
        log: Annotated[list[str], operator.add]

这段代码第一次出现了 `TypedDict`（类型字典）和 `Annotated`（附加规则标注）。

`TypedDict` 规定 State 有哪些字段以及各自的数据类型；`Annotated` 在类型之外给 `log` 绑定额外的合并规则。

它保存三样东西：

- `topic`：这次任务的主题
- `count`：流程已经推进到哪个计数
- `log`：每个节点留下的记录

初始值是：

    {"topic": "学 LangGraph", "count": 0, "log": []}

State 不是“模型的长期记忆”。它只是当前这次图运行时，节点共同读写的数据结构。怎样跨多次调用保存 State，要到第 03 课才讲。

【画什么】
一个方框列出 `topic` / `count` / `log` 三行。前两行右侧标「覆盖」，第三行标「累加」， 并用一条细线连到 `Annotated[list[str], operator.add]`。

【必须标注】
三个字段名；「覆盖」与「累加」的对比；触发累加的那段类型标注。

【不要出现】
数据库图标、时间轴、模型头像——State 不是存储，也不是记忆。

【替代文本（原样写进 <title> 与 <desc>）】
State 有三个字段，topic 和 count 被新值覆盖，log 因为带了 reducer 而累加。

【硬约束】
  - viewBox="0 0 720 H"，width="100%" height="auto"，不写固定 px 宽度
  - 颜色写成带兜底值的 CSS 变量：
      --ink #17231f  --muted #68736d  --card #fffdf7  --line #c9cfc7
      --lime #bafa4b（配 --on-lime #4d7100）  --green #355e48  --tertiary #9c432c
  - 圆角 rx="8"（小徽章 rx="2"）
  - 不用滤镜／渐变／blur；要立体感就用 2px 3px 的实心偏移矩形
  - font-family="var(--font-ui)"，正文 13px、标签 11px、标题 15px
  - 箭头用统一的 <marker>
  - 中文直接写在 <text> 里，不要转曲线

【自检】
  - 「必须标注」的每一条都能在 <text> 里找到
  - 「不要出现」的每一条确实没有出现
```
