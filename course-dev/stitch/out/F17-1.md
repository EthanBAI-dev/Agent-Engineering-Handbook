```text
## 改法二：退回到更早的一步，重新生成

如果改动会影响后续推理，就回到那一步之前再改：

    history = list(app.get_state_history(cfg))
    before_propose = [h for h in history if h.next == ("propose",)][0]
    forked = app.update_state(before_propose.config, {"target": "/tmp", "days": 30})
    out = app.invoke(None, forked)

实跑结果：

    重新生成的提案：清理 /tmp 下超过 30 天的文件
    结果：已执行：清理 /tmp 下超过 30 天的文件

这一次 `propose` 用新参数重新跑了一遍，提案和参数对上了。

代价是多花一次节点执行——如果那个节点会调用模型，就是多一次模型调用，要算进第 10 课的预算。

【画什么】
上栏「改当前 State」——`target` 与 `days` 变了，`plan` 保持旧值并标灰； 下栏「退回重新生成」——回到 propose 之前，三个字段全部更新。

【必须标注】
上栏那个没跟着变的 `plan`；下栏标「多跑一次节点」的代价。

【不要出现】
暗示 State 是一张依赖图——字段之间的推导关系藏在节点代码里。

【替代文本（原样写进 <title> 与 <desc>）】
直接改 State 只改动指定字段，依赖它的字段不会重算；退回重新生成才会全部更新。

【硬约束】
  - viewBox="0 0 720 H"，width="100%" height="auto"，不写固定 px 宽度
  - 颜色写成带兜底值的 CSS 变量：
      --ink #17231f  --muted #68736d  --card #fffdf7  --line #c9cfc7
      --lime #bafa4b（配 --on-lime #4d7100）  --green #355e48  --tertiary #9c432c
  - 圆角 rx="8"（小徽章 rx="2"）
  - 不用滤镜／渐变／blur；要立体感就用 2px 3px 的实心偏移矩形
  - font-family="var(--font-ui)"，正文 13px、标签 11px、标题 15px
  - 箭头用统一的 <marker>
  - 中文直接写在 <text> 里，不要转曲线

【自检】
  - 「必须标注」的每一条都能在 <text> 里找到
  - 「不要出现」的每一条确实没有出现
```
