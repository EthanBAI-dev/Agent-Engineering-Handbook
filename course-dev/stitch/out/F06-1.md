# F06-1｜同一张图，换个模型只有一处会变

- 课：第 06 课 · 模型、Prompt 与 Messages：哪些事归模型，哪些事归你的代码
- 形式：对照图 · `assets/lessons/06-same-graph-two-models.svg`
- 目标文件：`assets/lessons/06-same-graph-two-models.svg`

## 路线 A（推荐）· 让能写代码的模型直接产出 SVG

把下面整段贴给 Claude / Codex：

```text
【任务】写一个 SVG，落到 apps/web/public/assets/lessons/06-same-graph-two-models.svg

【这张图在讲什么】
## 同一张图，换个模型，回答就变了

实验里用同一张图跑了两个不同的模型：

    模型 A: 它是编排多步骤流程的框架。
    模型 B: 一个把 Agent 画成图来跑的库。
            消息条数 3，最后一条类型 AIMessage

图的结构一个字都没改：节点、边、消息条数、消息类型全都一样。变的只有那句话的内容。

反过来也成立：换一条边、加一个节点，模型再聪明也走不到你没连的地方。

【画什么】
上下两栏，同一张 `START → model → END`，同一组输入消息。 唯一不同的是最后那条 AIMessage 的正文，用高亮框住；其余（节点、边、消息条数、消息类型）都标「相同」。

【必须标注】
变的那一处；不变的四项。

【不要出现】
两栏画成不同的图结构——那会毁掉本课的论点。

【替代文本（原样写进 <title> 与 <desc>）】
同一张图换一个模型，只有最终回答的措辞变了，节点、边、消息条数和类型都不变。

【硬约束】
  - viewBox="0 0 720 H"，width="100%" height="auto"，不写固定 px 宽度
  - 颜色写成带兜底值的 CSS 变量：
      --ink #17231f  --muted #68736d  --card #fffdf7  --line #c9cfc7
      --lime #bafa4b（配 --on-lime #4d7100）  --green #355e48  --tertiary #9c432c
  - 圆角 rx="8"（小徽章 rx="2"）
  - 不用滤镜／渐变／blur；要立体感就用 2px 3px 的实心偏移矩形
  - font-family="var(--font-ui)"，正文 13px、标签 11px、标题 15px
  - 箭头用统一的 <marker>
  - 中文直接写在 <text> 里，不要转曲线

【自检】
  - 「必须标注」的每一条都能在 <text> 里找到
  - 「不要出现」的每一条确实没有出现
```
