## 互动实验：把请求路径排对

网页实验给出七张打乱的卡片：

    浏览器 fetch    ·    校验输入    ·    恢复 checkpoint
    model 节点     ·    tools 节点  ·    保存 checkpoint    ·    返回 JSON

你把它们排成一次完整请求的顺序，并标出哪几步发生在服务端。

通过条件：顺序正确，并且「校验输入」之后的所有步骤都被标为服务端。这也是本课唯一必须记住的安全事实——校验和密钥都在服务端那一侧。

【用户做什么】
用上移／下移把七个步骤排成一次完整请求的顺序。

【屏幕上变什么】
位置正确的那一项立刻变绿；每张卡片的副标题写着它发生在浏览器还是服务端。

【通过条件】
七个位置全部正确；顺带记住「校验之后的每一步都在服务端」。

【小屏怎么排】
卡片单列，移动按钮保持可点击尺寸。
