## 路线 A（推荐）· 让能写代码的模型直接产出 SVG

把下面整段贴给 Claude / Codex：

```text
【任务】写一个 SVG，落到 apps/web/public/assets/lessons/20-acceptance-paths.svg

【这张图在讲什么】
## 这张图为什么可信

四条理由，每一条都对应一条验收路径：

1. **风险表是代码**，模型改不了它，未登记的操作按 `forbid` 处理
2. **危险操作前必然经过审批**，拒绝路径不碰任何副作用
3. **副作用那一步有幂等键**，重试和重复提交都只生效一次
4. **全程有 checkpointer**，失败可以从原地恢复，而不是从头再来

「可信」不是一个感觉，是这四条各自有一次实跑作证。

【画什么】
同一张图画五遍（缩略），分别高亮五条路径：只读、批准、重复提交、拒绝、失败重试、禁止。 每条下方写预期结果，拒绝那条额外画一个「外部世界无变化」的断言标记。

【必须标注】
每条路径的预期结果；拒绝路径的外部断言。

【不要出现】
只画成功路径——本课的要点正是失败与拒绝路径。

【替代文本（原样写进 <title> 与 <desc>）】
五条验收路径分别覆盖只读、批准、重复提交、拒绝和失败重试，每条都有明确的预期结果。

【硬约束】
  - viewBox="0 0 720 H"，width="100%" height="auto"，不写固定 px 宽度
  - 颜色写成带兜底值的 CSS 变量：
      --ink #17231f  --muted #68736d  --card #fffdf7  --line #c9cfc7
      --lime #bafa4b（配 --on-lime #4d7100）  --green #355e48  --tertiary #9c432c
  - 圆角 rx="8"（小徽章 rx="2"）
  - 不用滤镜／渐变／blur；要立体感就用 2px 3px 的实心偏移矩形
  - font-family="var(--font-ui)"，正文 13px、标签 11px、标题 15px
  - 箭头用统一的 <marker>
  - 中文直接写在 <text> 里，不要转曲线

【自检】
  - 「必须标注」的每一条都能在 <text> 里找到
  - 「不要出现」的每一条确实没有出现
```
