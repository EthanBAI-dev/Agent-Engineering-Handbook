```text
## 这不是没写好，是结构决定的

有人会说：让 A 写得更全就行了。

那就试试推到极限——如果交接内容是**完整的 State**，会怎样？

那它和一张图就没有区别了，只是多了一次调用和一次序列化。你付出了成本，没换来任何隔离。

反过来，如果交接内容是**摘要**，那就一定会丢东西——摘要的定义就是丢东西。

    交接 = 完整 State  →  等于一张图，白付成本
    交接 = 摘要        →  一定丢信息

**没有第三种可能。**所以问题永远是：为了换来什么，值得丢这些？

【画什么】
上栏一张图——两步共享同一份 State，三条事实全部通过； 下栏两个 Agent——中间一道窄口，三条事实里只有两条挤过去，「日期」掉在口子外面。

【必须标注】
窄口标「交接」；下栏标出丢掉的那一条。

【不要出现】
把交接画成可以做到无损——无损就等于一张图。

【替代文本（原样写进 <title> 与 <desc>）】
一张图里两步共享完整现场，换成两个 Agent 后交接只传摘要，有信息在中途丢失。

【硬约束】
  - viewBox="0 0 720 H"，width="100%" height="auto"，不写固定 px 宽度
  - 颜色写成带兜底值的 CSS 变量：
      --ink #17231f  --muted #68736d  --card #fffdf7  --line #c9cfc7
      --lime #bafa4b（配 --on-lime #4d7100）  --green #355e48  --tertiary #9c432c
  - 圆角 rx="8"（小徽章 rx="2"）
  - 不用滤镜／渐变／blur；要立体感就用 2px 3px 的实心偏移矩形
  - font-family="var(--font-ui)"，正文 13px、标签 11px、标题 15px
  - 箭头用统一的 <marker>
  - 中文直接写在 <text> 里，不要转曲线

【自检】
  - 「必须标注」的每一条都能在 <text> 里找到
  - 「不要出现」的每一条确实没有出现
```
