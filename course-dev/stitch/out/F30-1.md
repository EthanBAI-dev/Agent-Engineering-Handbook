# F30-1｜三层记忆，三种生命周期

- 课：第 30 课 · 长期记忆与毕业项目：记住这个人，而不只是这段对话
- 形式：分层图 · `assets/lessons/30-three-memory-layers.svg`
- 目标文件：`assets/lessons/30-three-memory-layers.svg`

## 路线 A（推荐）· 让能写代码的模型直接产出 SVG

把下面整段贴给 Claude / Codex：

```text
【任务】写一个 SVG，落到 apps/web/public/assets/lessons/30-three-memory-layers.svg

【这张图在讲什么】
## 同一条事实说三次，只存一条

    store.put(memory_ns(user_id), fact, {"fact": fact})   # key 用事实本身

实跑结果：

    alice 的长期记忆共 2 条：['喜欢咖啡', '在学 LangGraph']

说了三次咖啡，只存一条。key 用事实本身，重复写入就是覆盖——**这是第 19 课的幂等换了个场景**。

如果 key 用时间戳或随机 id，记忆库会被同一件事塞满，检索时还要去重。

【画什么】
三层横条，从上到下：这一次调用带上哪些消息 / 这段对话说了什么 / 这个人是谁。 每层右侧标负责组件、对应课号和生命周期；最下层再按 `user_id` 切成两个互不相通的格子。

【必须标注】
三层是叠加不是替代；最下层的命名空间隔离。

【不要出现】
把三层画成同一个存储的三张表。

【替代文本（原样写进 <title> 与 <desc>）】
上下文管理、会话记忆和长期记忆是三层叠加的机制，长期记忆按用户命名空间彼此隔离。

【硬约束】
  - viewBox="0 0 720 H"，width="100%" height="auto"，不写固定 px 宽度
  - 颜色写成带兜底值的 CSS 变量：
      --ink #17231f  --muted #68736d  --card #fffdf7  --line #c9cfc7
      --lime #bafa4b（配 --on-lime #4d7100）  --green #355e48  --tertiary #9c432c
  - 圆角 rx="8"（小徽章 rx="2"）
  - 不用滤镜／渐变／blur；要立体感就用 2px 3px 的实心偏移矩形
  - font-family="var(--font-ui)"，正文 13px、标签 11px、标题 15px
  - 箭头用统一的 <marker>
  - 中文直接写在 <text> 里，不要转曲线

【自检】
  - 「必须标注」的每一条都能在 <text> 里找到
  - 「不要出现」的每一条确实没有出现
```
