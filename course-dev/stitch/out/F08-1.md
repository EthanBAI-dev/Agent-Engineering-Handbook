```text
## 接口契约：先定，再写

在写任何代码之前，先把这个接口的输入输出定下来。契约定不清楚，前后端会各写各的。

**请求**：

    {
      "thread_id": "a",
      "message": "北京天气怎么样？"
    }

**响应**：

    {
      "thread_id": "a",
      "reply": "北京今天晴，24 度。",
      "steps": ["model", "tools", "model"],
      "model_calls": 2
    }

三个字段值得解释：

- `thread_id` 原样回传，前端才能确认「这是刚才那段会话的回复」，而不是另一个请求的
- `steps` 让前端可以显示走过哪些节点，对应第 09 课的进度提示
- `model_calls` 让前端知道这次消耗了多少，对应第 10 课的限额

【画什么】
三条泳道——浏览器 / 网页服务端 / Python 服务。请求自上而下穿过： fetch → 校验 → 恢复 checkpoint → model → tools → 保存 checkpoint → 返回 JSON。

【必须标注】
一条竖线划出「浏览器」与「服务端」的边界；校验和密钥都在服务端那一侧。

【不要出现】
具体平台 logo——课程按方案 B 推进，不绑定某个平台。

【替代文本（原样写进 <title> 与 <desc>）】
请求从浏览器发出，在服务端完成校验与图的运行，只把挑选过的字段作为 JSON 返回。

【硬约束】
  - viewBox="0 0 720 H"，width="100%" height="auto"，不写固定 px 宽度
  - 颜色写成带兜底值的 CSS 变量：
      --ink #17231f  --muted #68736d  --card #fffdf7  --line #c9cfc7
      --lime #bafa4b（配 --on-lime #4d7100）  --green #355e48  --tertiary #9c432c
  - 圆角 rx="8"（小徽章 rx="2"）
  - 不用滤镜／渐变／blur；要立体感就用 2px 3px 的实心偏移矩形
  - font-family="var(--font-ui)"，正文 13px、标签 11px、标题 15px
  - 箭头用统一的 <marker>
  - 中文直接写在 <text> 里，不要转曲线

【自检】
  - 「必须标注」的每一条都能在 <text> 里找到
  - 「不要出现」的每一条确实没有出现
```
