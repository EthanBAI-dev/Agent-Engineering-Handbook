## InMemorySaver 能做什么

`InMemorySaver` 把 checkpoint 放在当前 Python（编程语言运行环境）进程的内存中。

Python 运行本地课程代码；这里的进程退出后，进程内存也会随之清空。

它非常适合学习、单元测试和本地小实验，因为不需要安装数据库。

但进程一旦退出，内存就清空。部署到无服务器平台时，不同请求也不保证落在同一个进程里。

所以它不能承担可靠的线上会话存储。

【画什么】
三层横条，从上到下：这一次调用带上哪些消息 / 这段对话说了什么 / 这个人是谁。 每层右侧标负责的组件和对应课号（第 14 课 / 本课 / 第 30 课）。

【必须标注】
本课只解决中间那层；上下两层各属于哪一课。

【不要出现】
把三层画成互相替代的方案——它们是叠加的。

【替代文本（原样写进 <title> 与 <desc>）】
上下文管理、会话记忆和长期记忆是三层不同的机制，本课只解决中间的会话记忆。

  - 不用滤镜／渐变／blur；要立体感就用 2px 3px 的实心偏移矩形
  - font-family="var(--font-ui)"，正文 13px、标签 11px、标题 15px
