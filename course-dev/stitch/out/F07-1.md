# F07-1｜密钥只存在于中间那一层

- 课：第 07 课 · 安全连接第一个模型 API：密钥放错地方，等于公开发布
- 形式：三层时序图 · `assets/lessons/07-key-layers.svg`
- 目标文件：`assets/lessons/07-key-layers.svg`

## 路线 A（推荐）· 让能写代码的模型直接产出 SVG

把下面整段贴给 Claude / Codex：

```text
【任务】写一个 SVG，落到 apps/web/public/assets/lessons/07-key-layers.svg

【这张图在讲什么】
## 正确的分层

    浏览器           你的服务端                模型服务商
      │                  │                        │
      │── 问题 ────────▶ │                        │
      │                  │── 问题 + API Key ────▶ │
      │                  │◀──────── 回答 ──────── │
      │◀──── 回答 ────── │                        │

浏览器只知道你的接口地址。密钥只存在于中间那一层。

这一层在第 08 课会变成 `/api/agent`。这一课先把密钥本身安顿好。

【画什么】
浏览器 / 你的服务端 / 模型服务商三列。箭头依次是：问题 → 问题+API Key → 回答 → 回答。 在「浏览器」这一列画一把带叉的钥匙，在「服务端」画一把正常的钥匙。

【必须标注】
浏览器那一列标「代码任何人都能看」；密钥只出现在服务端那一列。

【不要出现】
浏览器直连模型服务商的箭头——即使画成「错误示范」也容易被照抄。

【替代文本（原样写进 <title> 与 <desc>）】
浏览器只发问题收答案，API Key 只存在于你自己的服务端，浏览器永远不接触它。

【硬约束】
  - viewBox="0 0 720 H"，width="100%" height="auto"，不写固定 px 宽度
  - 颜色写成带兜底值的 CSS 变量：
      --ink #17231f  --muted #68736d  --card #fffdf7  --line #c9cfc7
      --lime #bafa4b（配 --on-lime #4d7100）  --green #355e48  --tertiary #9c432c
  - 圆角 rx="8"（小徽章 rx="2"）
  - 不用滤镜／渐变／blur；要立体感就用 2px 3px 的实心偏移矩形
  - font-family="var(--font-ui)"，正文 13px、标签 11px、标题 15px
  - 箭头用统一的 <marker>
  - 中文直接写在 <text> 里，不要转曲线

【自检】
  - 「必须标注」的每一条都能在 <text> 里找到
  - 「不要出现」的每一条确实没有出现
```
