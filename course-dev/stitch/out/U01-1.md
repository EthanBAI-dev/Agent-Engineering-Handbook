## 互动实验：每次只执行一个节点

在网页动画中点击“执行下一步”。每次点击只做一件事：

1. 高亮当前执行的 Node
2. 高亮刚经过的 Edge
3. 显示 `count` 的旧值和新值
4. 显示 `log` 新追加的一项

第一次运行时，先不要点“自动运行”。单步观察下面这条变化：

    count: 0 → 1
    log: [] → ["planning: 学 LangGraph"]

然后继续执行，直到流程进入 `END`。

默认阈值为 `4`。完整运行后，经过本机验证的结果是：

    work 执行 3 次
    最终 count = 4
    log 一共有 5 条

为什么不是 4 次？因为 `plan` 已经先把 `count` 从 0 加到了 1。`work` 从 1 开始执行，直到 count 达到 4。

【用户做什么】
点「执行下一步」逐节点推进；跑完后把阈值从 4 改成 6 再跑一遍。

【屏幕上变什么】
当前 Node 高亮；刚走过的 Edge 高亮；`count` 显示旧值→新值；`log` 追加一项。

【通过条件】
阈值 6 跑完后，`work` 恰好执行 5 次、`count` 为 6、`log` 共 7 条。

【小屏怎么排】
流程横向滚动，State 面板移到流程图下方。
