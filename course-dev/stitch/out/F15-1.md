## 路线 A（推荐）· 让能写代码的模型直接产出 SVG

把下面整段贴给 Claude / Codex：

```text
【任务】写一个 SVG，落到 apps/web/public/assets/lessons/15-across-processes.svg

【这张图在讲什么】
## 图一个字都不用改

对比两行：

    # 教学版
    app = graph.compile(checkpointer=InMemorySaver())

    # 上线版
    app = graph.compile(checkpointer=SqliteSaver.from_conn_string(path))

节点、边、条件判断、消息处理，全都不动。

这正是 checkpointer 被设计成可替换组件的原因：存储是部署问题，不是业务逻辑问题。第 03 课说「换成 SQLite 或 Postgres，图本身一个字都不用改」，这一课把它验证了。

【画什么】
上栏一个进程框，内存 checkpointer 画在框内，进程消失时里面的东西跟着消失； 下栏 checkpointer 画在框外的文件里，新进程只拿到一条文件路径就能读到。

【必须标注】
「进程边界」那条线；下栏标「子进程没有继承任何内存」。

【不要出现】
把 InMemorySaver 画成有持久化图标。

【替代文本（原样写进 <title> 与 <desc>）】
内存检查点随进程消失，外部存储写在进程之外，新进程只凭文件路径就能读回。

【硬约束】
  - viewBox="0 0 720 H"，width="100%" height="auto"，不写固定 px 宽度
  - 颜色写成带兜底值的 CSS 变量：
      --ink #17231f  --muted #68736d  --card #fffdf7  --line #c9cfc7
      --lime #bafa4b（配 --on-lime #4d7100）  --green #355e48  --tertiary #9c432c
  - 圆角 rx="8"（小徽章 rx="2"）
  - 不用滤镜／渐变／blur；要立体感就用 2px 3px 的实心偏移矩形
  - font-family="var(--font-ui)"，正文 13px、标签 11px、标题 15px
  - 箭头用统一的 <marker>
  - 中文直接写在 <text> 里，不要转曲线

【自检】
  - 「必须标注」的每一条都能在 <text> 里找到
  - 「不要出现」的每一条确实没有出现
```
