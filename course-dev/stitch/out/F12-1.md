# F12-1｜两种静默失败

- 课：第 12 课 · State Schema：写错字段名不会报错，只会静静地什么都不发生
- 形式：对照图 · `assets/lessons/12-silent-drops.svg`
- 目标文件：`assets/lessons/12-silent-drops.svg`

## 路线 A（推荐）· 让能写代码的模型直接产出 SVG

把下面整段贴给 Claude / Codex：

```text
【任务】写一个 SVG，落到 apps/web/public/assets/lessons/12-silent-drops.svg

【这张图在讲什么】
## 第二种静默：节点写错字段名

这一种更常见，也更难查：

    def typo_node(state: State) -> dict:
        # 想写 answer，手滑写成 answr
        return {"answr": "这句话永远不会出现"}

实跑结果：

    节点返回了 answr，跑完之后 answer = ''

没有异常，没有警告。你会以为是模型没给出内容、是提示词不对、是条件边走错了——一路查下去，其实只是拼错了一个字母。


**记住这条排查顺序：结果「没变化」时，先怀疑字段名，再怀疑模型。**

【画什么】
左边「多传的字段」——一个 `user_id` 从输入飘向 State 边界后消失； 右边「写错字段名」——节点返回 `answr`，同样在边界外消失。两处都画一个灰色的「无异常」标记。

【必须标注】
两处都「没有报错、也没有生效」；State 边界画成一道实线。

【不要出现】
红色报错图标——它们的危险恰恰在于不报错。

【替代文本（原样写进 <title> 与 <desc>）】
不在 schema 里的输入字段和写错名字的返回字段都会被静默丢弃，不产生任何错误提示。

【硬约束】
  - viewBox="0 0 720 H"，width="100%" height="auto"，不写固定 px 宽度
  - 颜色写成带兜底值的 CSS 变量：
      --ink #17231f  --muted #68736d  --card #fffdf7  --line #c9cfc7
      --lime #bafa4b（配 --on-lime #4d7100）  --green #355e48  --tertiary #9c432c
  - 圆角 rx="8"（小徽章 rx="2"）
  - 不用滤镜／渐变／blur；要立体感就用 2px 3px 的实心偏移矩形
  - font-family="var(--font-ui)"，正文 13px、标签 11px、标题 15px
  - 箭头用统一的 <marker>
  - 中文直接写在 <text> 里，不要转曲线

【自检】
  - 「必须标注」的每一条都能在 <text> 里找到
  - 「不要出现」的每一条确实没有出现
```
