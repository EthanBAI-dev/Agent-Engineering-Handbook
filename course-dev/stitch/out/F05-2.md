## 失败时应该回到哪里

完整 Agent 必须为失败留出路线。

### model 生成了不存在的工具名

不要让程序崩溃后沉默。

tools 应返回结构化错误，让结果回到 model，model 可以改用合法工具或向用户说明失败。

### 文件在审批期间被别人移动了

批准值不能证明目标仍然存在。

risky_tools 执行前必须重新检查路径、允许目录和目标状态。审批的是一个明确动作，不是一张永久通行证。

### 恢复时进程已经重启

`InMemorySaver`（内存检查点保存器）中的数据会在进程退出后丢失。

`InMemorySaver` 把 checkpoint 临时放在当前进程内存中，只适合教学和测试。

这正是教学版与生产版的分界：线上需要外部持久化 checkpointer，而不是依赖某个进程一直活着。

### 同名文件会被覆盖

移动工具应该明确选择：拒绝、重命名或再次审批。

不能把覆盖行为藏在工具内部默认执行，因为用户批准的是“整理文件”，不一定批准“丢失旧文件”。

【画什么】
左右两栏同一张蓝图，右栏把四处教学版部件换成生产版并标出课号： 内存 checkpointer→外部存储（15）、无账号→身份与隔离（29）、无校验→参数白名单（28）、无记录→审计（27）。

【必须标注】
四处差距各自去哪一课解决。

【不要出现】
把差距说成「小改动」——它们各占一课。

【替代文本（原样写进 <title> 与 <desc>）】
教学版蓝图有四处需要替换成生产版：持久化存储、账号隔离、参数校验和审计记录。

【硬约束】
  - viewBox="0 0 720 H"，width="100%" height="auto"，不写固定 px 宽度
  - 颜色写成带兜底值的 CSS 变量：
      --ink #17231f  --muted #68736d  --card #fffdf7  --line #c9cfc7
      --lime #bafa4b（配 --on-lime #4d7100）  --green #355e48  --tertiary #9c432c
  - 圆角 rx="8"（小徽章 rx="2"）
  - 不用滤镜／渐变／blur；要立体感就用 2px 3px 的实心偏移矩形
  - font-family="var(--font-ui)"，正文 13px、标签 11px、标题 15px
  - 箭头用统一的 <marker>
  - 中文直接写在 <text> 里，不要转曲线

【自检】
  - 「必须标注」的每一条都能在 <text> 里找到
  - 「不要出现」的每一条确实没有出现
