## 路线 A（推荐）· 让能写代码的模型直接产出 SVG

把下面整段贴给 Claude / Codex：

```text
【任务】写一个 SVG，落到 apps/web/public/assets/lessons/22-empty-fanout.svg

【这张图在讲什么】
## 修法：空集合单独走一条路

    def route_or_empty(state: Overall):
        if not state["documents"]:
            return "nothing_to_do"
        return [Send("review_one", {"document": doc}) for doc in state["documents"]]

条件函数可以返回一个节点名，也可以返回一串 `Send`。实跑结果：

    零份：没有需要评审的文件
    两份：共 2 份，平均 4.5 分，最高是 报告BB（5 分）

【画什么】
左栏三份文件——三个 map 任务汇入 reduce；右栏零份文件——map 一个都没有， reduce 节点整个画成虚线灰框，旁边标「没有报错，也没有执行」。

【必须标注】
reduce 只有一条来自 map 的入边；右栏结果字段停在初始值。

【不要出现】
在右栏画报错图标——它的危险正是不报错。

【替代文本（原样写进 <title> 与 <desc>）】
扇出为零时没有 map 任务，只依赖 map 的 reduce 节点也不会执行，结果字段静默保持初始值。

【硬约束】
  - viewBox="0 0 720 H"，width="100%" height="auto"，不写固定 px 宽度
  - 颜色写成带兜底值的 CSS 变量：
      --ink #17231f  --muted #68736d  --card #fffdf7  --line #c9cfc7
      --lime #bafa4b（配 --on-lime #4d7100）  --green #355e48  --tertiary #9c432c
  - 圆角 rx="8"（小徽章 rx="2"）
  - 不用滤镜／渐变／blur；要立体感就用 2px 3px 的实心偏移矩形
  - font-family="var(--font-ui)"，正文 13px、标签 11px、标题 15px
  - 箭头用统一的 <marker>
  - 中文直接写在 <text> 里，不要转曲线

【自检】
  - 「必须标注」的每一条都能在 <text> 里找到
  - 「不要出现」的每一条确实没有出现
```
