LESSON 012 / 8

一句话说完

Agent 每走到一个 Node，就读一次 State，写回一小块变化，再沿着 Edge 去下一站。

没有别的了。所谓「自主」，是这个循环跑了很多圈。

LESSON 013 / 8

State：共享的现场

不是聊天记录，是所有节点都能读、都能写的那份数据。

谁都能看见现在是第几步、上一步产出了什么——这是节点之间唯一的通信方式。

class State(TypedDict):
    count: int
    log: list[str]
LESSON 014 / 8

Node：只做一小步

输入是 State，返回的是局部更新——只返回你改的那几个键。

不用把整个 State 抄一遍还回去，这是新手最容易写错的地方。

def work(state):
    return {"count": state["count"] + 1}
LESSON 015 / 8

Reducer 决定覆盖还是累加

同样是返回一个值，count 被覆盖，log 却在累加。

差别不在节点里，在 State 定义那一行——加没加 reducer。

count: int                       # 覆盖
log: Annotated[list, add]        # 累加
LESSON 016 / 8

循环藏在条件边里

模型没有神秘意志。

所谓「它会自己反复思考」，只是图里有一条会 return 回前面节点的条件 Edge。你写的。

去掉它就不循环了
LESSON 017 / 8

易踩坑什么时候别画成图

一次性、无分支、不需要重试的任务，直接调模型就行。

图是为了循环和分支存在的。没有这两样还画图，只是给自己加班。

LESSON 018 / 8

三句话带走

  1. State 保存当前现场
  2. Node 读 State，返回局部更新
  3. Edge 决定下一步，条件边制造循环
