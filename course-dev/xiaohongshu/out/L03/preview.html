LESSON 032 / 8

模型本身没有记忆

每一次调用对模型来说都是全新的，它不记得上一句。

你感受到的「记忆」，全部是编排层每次把历史消息重新带进去造出来的。

LESSON 033 / 8

checkpoint 存的不是摘要

是整份 State 的快照，一步一存。

所以恢复的时候不是「大概记得聊过什么」，是精确回到那一刻的现场。

app = graph.compile(
    checkpointer=InMemorySaver()
)
LESSON 034 / 8

thread_id 给快照分组

像酒店房号。同一个 id 接着上次跑，换一个 id 就是全新对话。

它不在 State 里，在运行配置里传。

config = {"configurable":
  {"thread_id": "a"}}
LESSON 035 / 8

会话记忆 ≠ 长期记忆

thread 记的是「这段对话说了什么」，不是「这个人是谁」。

换个会话就不认识你了——那是另一层机制（store），第 30 课才讲。

三层记忆别混
LESSON 036 / 8

InMemorySaver 只适合学习

名字已经说了：存在内存里。进程一关就全没了。

要活过重启得换 SqliteSaver 或数据库版本，第 15 课。

LESSON 037 / 8

易踩坑thread_id 不是身份验证

换个参数就能读到别人的会话——这不是攻击，只是换了个参数。

归属检查必须在服务端。这个坑第 29 课会专门拆。

LESSON 038 / 8

三句话带走

  1. checkpointer 保存 State 快照
  2. thread_id 把快照归到不同会话
  3. InMemorySaver 适合学习，不是生产数据库
