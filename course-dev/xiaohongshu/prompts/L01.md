## 正文文案

```text
「Agent 会自主思考」这句话害了很多人。

拆开看其实特别朴素：每走到一个节点，读一次共享状态，写回一小块变化，再沿着边去下一站。所谓「自主循环」，就是图里有一条会绕回前面节点的条件边——你自己写的那条。

三个词讲完：State 存现场，Node 做一步，Edge 定下一步。

最容易写错的是 Node 的返回值：只返回你改的那几个键就行，不用把整个 State 抄一遍。还有 reducer——同样返回一个值，为什么 count 是覆盖、log 是累加？答案在 State 定义那一行。

#AIAgent #LangGraph #大模型应用开发 #AI学习 #程序员
```
