## 正文文案

```text
「为什么我的 Agent 老是失忆」——因为模型本身就没有记忆。

每次调用对它来说都是全新的。你感受到的记忆，全是编排层每次把历史重新带进去造出来的。

LangGraph 里这件事由 checkpointer 做：每一步存一份完整的 State 快照，thread_id 负责把快照分组。同一个 id 接着上次跑，换一个 id 就是全新对话，像酒店房号。

两个容易踩的坑：一是 InMemorySaver 进程一关就没了，别拿去生产；二是 thread_id 不是身份验证——换个参数就能读到别人的会话，归属检查必须在服务端做。

```
