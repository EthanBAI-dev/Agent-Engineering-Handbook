## 正文文案

```text
很多人的 Agent 就是「模型 + 一堆工具」，然后发现上线之后到处是洞。

还差三样：记忆、审批、以及撑住这两样的 checkpointer。

这条把前四课拼成一张完整蓝图，五步：State 存什么 → 列节点不列口号 → 先闭合普通工具循环 → 危险工具绕去审批 → checkpointer 兜住等待。

有个反直觉的建议：不要把所有工具都设成危险。每次都要批的系统，人会闭着眼睛点通过——那比不设审批还糟。

判断一个节点合不合格也有标准：你能不能说清它读什么、写什么。「智能分析用户意图」说不清，所以它不是节点。

#AIAgent #LangGraph #系统设计 #大模型应用开发 #程序员
```
