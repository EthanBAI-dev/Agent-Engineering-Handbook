# 小红书图文：把课程做成能发的卡片

先测 00–05 六课，每课一组卡片（封面 + 6–7 张内页 + 尾页）。

## 直接能用的东西

```bash
node build.mjs              # 渲染全部：out/L00…L05 的 PNG + prompts/ 的提示词
node build.mjs --only 03    # 只做第 03 课
```

- `out/L0x/*.png` —— **1242 × 1656，正好 3:4，可以直接发**
- `prompts/L0x.md` —— 标题候选 / Stitch 提示词 / 正文文案 / 话题 / 插画提示词
- `out/L0x/preview.html` —— 同一份版式的网页，**拖进 Stitch 当参考图用**

内容只有一个来源：`cards.json`。改文字改这里，重跑一次就全更新。

---

## 为什么图片是 1242 × 1656

小红书竖版 3:4 在信息流里占位最大，同一条内容比 1:1 多出约三分之一的曝光面积。
1242 × 1656 是 3:4 里的常用高清尺寸（621 × 828 CSS px 的 2 倍图）。

`build.mjs` 用 `clip` 精确裁切而不是直接截元素——直接截会因为子像素把宽度变成 1244，
比例就不是 3:4 了，小红书会自己再裁一刀，通常裁掉封面标题的一角。

## 标题的两条硬规则

1. **上限 20 个字**（中英文都算 1 个），超出直接截断。`prompts/` 里每个候选都标了字数。
2. **前 10 个字决定点不点开**。所以把冲突放在最前面：
   「模型不会亲手算」「前端弹框不算人工审批」「Agent 为什么会失忆」。

话题标签里**不能有空格**，`#AI Agent` 会从空格断开，要写成 `#AIAgent`。

## 两条路线，选一条

### 路线 A · 直接用本地渲染（现在就能发）

`out/` 里已经是成品。版式跟网站是同一套配色和字体阶梯，风格统一。
改文案就改 `cards.json` 里的 `pages[].b`，重跑 `node build.mjs`。

脚本会自检文字有没有排溢出（超出卡片会被裁掉），溢出时命令行会提示第几张要删字。

### 路线 B · 交给 Stitch 出设计，再用脚本导出

1. 打开 `prompts/L0x.md`，把「Stitch 提示词」整段复制。
2. 新建 Stitch 对话，粘进去，**拖入 `out/L0x/01.png` 当参考图**，发送。
3. 导出 HTML，存到本目录，然后：

```bash
node build.mjs --shoot 你导出的文件.html
```

脚本会找 `class="xhs-card"` 的元素逐张截图（提示词里已经要求 Stitch 打这个类名），
比例不是 3:4 时会警告并按 3:4 裁切。产物在 `out/<文件名>/`。

**别手工截图。**手工截出来的尺寸不对，小红书二次裁切会切掉标题。

## 每课发布清单

打开 `prompts/L0x.md`，从上往下抄：

- [ ] **标题** —— 三个候选选一个（第一个是主推），确认 ≤ 20 字
- [ ] **图片** —— `out/L0x/` 全部，按 01、02… 顺序上传，第 1 张是封面
- [ ] **正文** —— 直接复制，末尾已经带好话题标签
- [ ] **插画**（可选）—— 想额外配一张时用那段提示词，注意它要求画面内不出现文字

## 插画为什么不让出现文字

图像模型画中文几乎必错（缺笔画、错字、糊）。
所有需要精确文字的地方都由卡片排版承担，插画只负责气氛。

## 内容脚本怎么写（改 cards.json 时看这里）

```jsonc
{
  "n": "01", "unit": "图与状态",
  "titles": ["…", "…", "…"],          // 三个候选，都要 ≤ 20 字
  "cover": {
    "big": "三行\n主标题\n每行一句",   // 换行由你决定，别让 Stitch 自己断
    "sub": "副标题一行",
    "hl": "会跑的图"                   // 主标题里要用柠檬绿高亮的那几个字
  },
  "pages": [{
    "h": "小标题",
    "b": "正文。**这样**会被柠檬绿下划线高亮，`这样` 会变成行内代码。\n\n空行分段。",
    "code": "可选：深色代码块",
    "tag": "可选：底部一条强调语",
    "warn": true                       // 可选：标成「易踩坑」，强调条变珊瑚色
  }],
  "end": ["带走一", "带走二", "带走三"],
  "caption": "正文文案，第一段就是钩子",
  "art": "插画描述，不含文字"
}
```

**一张卡只讲一件事**，正文 3–5 行。塞满的卡片在手机上没人看。
脚本会在渲染时检查溢出，但看不出「虽然放得下但太密」——那要自己看图判断。
