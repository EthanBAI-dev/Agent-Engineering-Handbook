# Agent Hands-on Lab · 产品构想

## 一句话版本

一个把技术文章变成可操作实验的 Agent 入门网站：读者先读懂“为什么”，再亲手执行每一步、观察 State、修改参数，最后用小挑战证明自己真的学会了。

## 完整版本

Agent Hands-on Lab 不是把传统教程原样搬到网页，也不试图复刻一套昂贵的云端开发环境。它把文章与互动动画编排成同一条学习路径：当文字解释到一个抽象概念时，旁边的流程图立刻可以运行；当节点开始执行时，读者能同步看到数据怎样变化；读完一节后，还要亲手修改条件并通过验证。

第一阶段不要求安装环境，也不需要 API Key。读者先在浏览器里建立对 State、Node、Edge 和工具循环的直觉。后续再逐层接入真实 Python LangGraph、模型 API、调用限额、账号、数据库和长期记忆，让产品能力与学习难度一起增长。

## 核心教学模式：读、动、改、证

1. **读**：用短文章回答一个明确问题，不堆概念
2. **动**：单步运行动画，把抽象机制变成可观察过程
3. **改**：只开放一个关键参数，让学习者主动制造不同结果
4. **证**：用自动检查给出明确的通过条件，不靠“好像看懂了”

每一章都按这个闭环设计，但文章结构不机械套模板。互动出现在哪里，取决于那个概念最容易在哪一步失去直觉。

## 两章内容边界

- 第一章《Agent 不是一次回答，而是一条会改变 State 的路》：拥有 State、Node、Edge、reducer 和条件循环
- 第二章《模型不会亲手算：它先决定要不要调用工具》：拥有 MessagesState、ToolNode、工具调用和 ReAct 闭环
- 记忆、人工审批、真实模型费用和后端执行全部留到后续章节

## 30 课的信息架构

- 首页只负责产品说明、学习方式和 30 课课程地图
- 每一课拥有独立 URL、标题、摘要和阅读位置，不把 30 课堆成一页
- 课尾固定提供上一课、下一课、返回目录和 01–30 课次跳转
- 未完成课程显示为锁定课位，不创建空白页面或假链接
- 第 01–30 课的命名、概念归属和来源统一维护在 `course-dev/30-lesson-curriculum-map.md`；单课开写前仍须补齐实验契约和官方文档校验

## 视觉与交互模式

- 页面像一篇可沉浸阅读的长文章，而不是后台仪表盘
- 每章由“短文 → 互动实验 → 解释 → 挑战 → 真实代码”组成
- 动画永远支持单步执行，自动播放只是辅助
- 变化中的节点、Edge 和 State 使用同一套颜色语义
- 手机端保持文章优先，流程图可以横向滚动，操作按钮保持足够大
