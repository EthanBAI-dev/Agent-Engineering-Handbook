# 数据图规则

配图分两类，规则不同：

- **示意图**：流程、类比、分类、对比卡片。规则见 `配图规则.md`。
- **数据图**：曲线、增长趋势、耗时对比——**任何声称「这就是实际跑出来的样子」的图。**

本文件管的是第二类。

---

## 一、数据图必须来自真实运行

**不允许摆几个方块拼出一张「看起来像那么回事」的趋势图。**

反面例子：讲上下文越滚越长，画三根越来越高的柱子，柱高是随手定的。
读者看完仍然不知道到底涨多快，也没法把正文里「每次涨约 580 字」这句话和图上的东西对上。
**这类图不是画得不好，是它根本没在传递知识。**

数据来源按优先级：

1. **课程脚本的真实输出**（`课程代码/lessons/lessonNN_*.py`）。最有说服力，读者能自己复现。
2. **与正文例子严格对应的构造数据**。正文说「查三个城市」，就照三个城市跑，
   参数写进脚本注释。
3. 纯示意——**只有当图讲的是概念关系而不是实际数值时才允许**
   （例如「存档器、长期存储各自管什么」）。

真实数据还有个附带好处：图注可以写出脚本名，读者能自己核对。

### 生成图的数据必须和正文同源

**不要为了画图另跑一遍、另写一段代码。** 图和正文引用同一次运行的输出。
把归一化、单位、取样间隔放在同一处，使图和正文可以逐项核对。

## 二、本课程的数据图都画什么

| 要证明的事 | 数据从哪来 | 画成什么 |
| --- | --- | --- |
| 上下文随轮数增长 | 脚本每轮打印的消息条数与字数 | 折线，横轴轮数，纵轴字数 |
| 有无归并器的差别 | 同一次运行的两种配置输出 | 两栏对比，同一纵轴 |
| 并行比串行快多少 | 脚本计时 | 两根柱（横轴是真离散类别） |
| 图的结构 | `draw_mermaid()` 真实输出 | 流程图，见 `配图规则.md` |
| 存档历史的分叉 | `get_state_history()` 真实快照 | 时间轴 |

## 三、出现数值就必须有刻度

图上写了「第 4 轮 1767 字」，读者就得能在轴上找到 1767 的位置。
**没有刻度的曲线只是示意图，不能承担数值论证。**

判断标准很简单：**图注或图内出现了任何具体数值，对应的轴就必须有刻度和单位。**

- 差：曲线画在一个空白方框里，下面用文字写「从 27 涨到 1767」。
- 好：横轴标 `1 / 2 / 3 / 4` 与单位「轮」，纵轴标 `0 / 600 / 1200 / 1800` 与单位「字」。

刻度字号按版式给：手机版原始字号不低于 13.5，否则缩到 360 px 后会低于 11.5 的下限。

**纯概念图不受此条约束**——它们本来就不声称任何数值。

## 四、坐标轴的三件事必须核对

1. **单位写清楚。** 是「字」还是「词元」？是「毫秒」还是「秒」？
   **字数和词元数不是一回事**，中文尤其差得远，混用会误导读者。
2. **起点是不是零。** 纵轴从非零开始会把差异放大好几倍。
   要截断就在图注里说明。
3. **横轴是连续量还是离散类别。** 轮数、步数、耗时是连续量，画曲线；
   「三种归并器」「四种状态写法」才是离散类别，才用柱状图。

## 五、教学简化必须就地标注

- 为了让曲线好看而只跑三轮，就写明「只跑了三轮，实际任务会长得多」。
- 用构造数据代替真实模型输出的，图注必须写明。
- **凡是依赖模型输出的数据图，必须注明「你跑出来可能不一样」**——
  模型行为不确定，框架行为才是确定的。

## 六、图注写图上看得见、正文没写的东西

最常见的浪费，是图注把正文那句话再说一遍。**图注应该引导读者去看图上的某个具体位置。**

- 差：*图 2：上下文随轮数增长。*（正文刚说过）
- 好：*图 2：第 1 轮到第 2 轮那一段最陡——一次工具返回就把整段对话顶高了一大截，
  后面每一轮都在为这一坨重复付费。*

好图注的三种写法：

1. **指认**：「注意最后那一格，它比第一格高了 65 倍。」
2. **对应**：「左图第 3 轮那个拐点，就是右图里报错的那一步。」
3. **交代来源**：「数据来自 `lesson05_hand_written_agent.py` 的实验二，你可以自己跑一遍。」

## 七、交付前的检查

- [ ] 每张数据图的数值都来自脚本真实输出，不是摆出来的
- [ ] 图和正文引用同一次运行，没有为画图另跑一遍
- [ ] 出现数值的轴都有刻度和单位
- [ ] 单位写清楚了（字／词元、毫秒／秒不混用）
- [ ] 纵轴截断的已在图注说明
- [ ] 连续量画曲线，只有真离散类别才用柱状图
- [ ] 依赖模型输出的图已注明「你跑出来可能不一样」
- [ ] 图注指向图上的具体位置，没有复述正文
