# 原始素材：音频课程 skill 的参考文件

**这些是原样保存的音频信号处理课程配套文件，尚未适配到 LangGraph 课程。**

保留原样是有意的：改写之前先留底，避免适配时丢掉原意。
**未经确认，不要直接把这些文件当成本课程的规则来执行**——
其中一部分与本 skill 现有条款冲突，见下表。

## 迁移评估

| 文件 | 可迁移性 | 说明 |
| --- | --- | --- |
| `report-template.md` | **高，几乎可直接用** | 审校报告 A–L 节。本 skill 目前只提「审校报告」四个字，没有格式。这份可直接补上，只需把 D 节引用的零基础规则指向本 skill 的 `零基础自检.md` |
| `mobile-figures.md` | **高** | 窄屏版式、有效字号公式（SVG 字号 × min(1, 360/viewBox 宽度) ≥ 12 px）、语义转置表格的写法，全部与领域无关。「课程位置图」一节对 31 讲的系列尤其适用 |
| `article-shape.md` | **高，但与现有条款有冲突** | 自然骨架、内部检查点表、常见失败模式都能直接用。**冲突见下节** |
| `data-figures.md` | **中，需大幅改写** | 「数据图必须来自真实计算」「出现数值的轴必须有刻度」「颜色跟着含义走不按面板序号轮换」「图注写图上看得见、正文没写的」四条完全适用。但声谱图、FFT、magma 色标、librosa、栅格嵌 SVG 等大半篇幅是音频专有，需要换成本课程的对应物 |
| `markdown-math.md` | **低，但留着无害** | 本课程几乎不出现公式。若将来某讲要写复杂度或词元计算，可直接启用 |

## 与本 skill 现有条款的冲突（改写前必须裁决）

| 冲突点 | `article-shape.md` 说 | 本 skill 现在说 | 备注 |
| --- | --- | --- | --- |
| **导读长度** | 两到三句，60–120 个汉字，依次交代「现实问题—经过哪些概念—读完能判断什么」 | **只有一行**，且不写「读完能做到」那一行 | 本 skill 的说法更严。第 02、05 讲按一行写的，读起来不拖沓。**倾向保留本 skill 的一行制**，但 60–120 字那条值得试写一篇对比 |
| **结尾标题** | `## 这一课得到了什么，下一课接着讲什么` | `## 这一讲得到了什么，下一讲接着讲什么` | 只是「课／讲」用词差异，本课程统一用「讲」 |
| **标题结构** | 「1～3 个必要技术词 + 一个具体问题或结果」 | 「标题要有主语和谓语，术语不顶在最前面」 | 两条不矛盾，可合并 |

## 本课程的对应物（改写 `data-figures.md` 时照这个换）

| 音频课的「数据图」 | 本课程的对应物 |
| --- | --- |
| 波形、频谱、声谱图 | **`draw_mermaid()` 导出的真实图结构** |
| 从真实录音算出来的曲线 | **脚本实跑出来的数字曲线**：上下文字数随轮数增长、耗时、步数、词元用量 |
| magma 色标、栅格嵌 SVG | 用不上。本课程没有连续像素场 |
| 「不允许用色块摆出一张看起来像声谱图的图」 | **「不许手画一张『大概是这样』的流程图」**，已在本 skill 第五节写明 |

## 迁移的验收结果

用新词表跑已写的两讲，首轮 **6 个 ERROR**，全部是真问题：
两讲都缺导读，开头出现未解释的「模型」「图」「循环」「大模型」。
逐条修掉后**ERROR 与 WARN 均为 0**，两个脚本仍正常运行。

一个有价值的发现：**检查器不把导读里的解释算数**，正文第一次真用时必须重新解释。
这与 `article-shape.md` 的规定完全一致，说明这套规则和检查器是自洽的。
