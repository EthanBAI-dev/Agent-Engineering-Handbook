# 零基础自检

动笔前读一遍，成文后逐条过一遍。

## 一、读者模拟

想象一个具体的人：**没写过 Python，没用过命令行，不知道什么是函数返回值。**

逐段读你写的东西，每段问：

1. 这段里有几个他没见过的词？**超过一个就重写。**
2. 有没有用一个陌生词去解释另一个陌生词？**有就重写。**
3. 他读完这段，能说出「刚才那段在讲什么」吗？说不出就拆。
4. 这段能删吗？删了不影响他动手的，就删。

## 二、术语五关

任何专业词进正文前：

1. 这段话必须用它才讲得通吗？不是就删。
2. 能先说人话、后给学名吗？
3. 能落到具体场景、动作或日常现象上吗？
4. 解释里有没有引入新的没解释过的词？
5. 删掉它，读者还能拿到核心意思吗？能就删。

顺序永远是：**具体场景 → 日常解释 → 专业名称 → 简单例子**。

## 三、句子级自检

| 检查项 | 不合格的样子 |
| --- | --- |
| 主语谓语写出来了吗 | 「状态在节点之间流转」 |
| 动词贴着主体吗 | 「agent 自己思考下一步」 |
| 每个数字后面有「所以呢」吗 | 「默认上限是 10007 步。」句号完了 |
| 比方接回主体了吗 | 举完流水线就走，没说回图 |
| 导读盖住后理解成本变高了吗 | 没变高说明导读是废话 |

## 四、密度检查

- 一段最多 3 句。超过就分段。
- 一句话只说一件事。从句、括号补充、破折号插入语全部拆开。
- 一段最多一个新的核心概念。
- 一段扛着三个以上陌生词，必须拆开或重写。

## 五、发布门槛

**零基础读者理解度低于 8/10 就不发，其他维度分数再高也不发。**

打分方式：找一段你自己最不确定的正文，逐句问「他读到这里会卡住吗」，
卡住一次扣一分。

## 六、成文后必扫的词

读者正文中命中必须清零：

```
notebook  Notebook  单元格  幻灯片  Module  模块 \d  官方课程  源课程  原课程
```

延伸阅读小节里的链接不算正文措辞。
