# 发布前自查清单

复制到 PR 描述里逐项打勾。

## 可读性（主版本的硬指标）
- [ ] 开头就是「只看一句话的话」，给出可直接抄走的那一句
- [ ] 找一个没用过这个工具的人试读，标出他卡住的地方
- [ ] **每段不超过 3 句**，段间有空行
- [ ] 没有从句嵌套、括号补充、破折号插入语
- [ ] 能不用的术语都删了；必须用的先给例子再给名词
- [ ] **正文里没有英文原文引用**（挪到文末）
- [ ] **正文里没有用表格讲道理**（表格只留给文末速查表）
- [ ] 小节数 ≥ 12，单节 ≤ 300 字
- [ ] 小标题是人话或问句，不是名词短语
- [ ] 有至少一个生活化比喻
- [ ] 有「我这情况不适用怎么办」的兜底章节
- [ ] 文末有两列速查表 + 一句话总结
- [ ] 深的内容已经挪到 `deep-dive.md`，主版本没有残留

## 内容
- [ ] 开头 3 句内出现具体痛点，没有冗长背景
- [ ] 有「机制」章节，解释了为什么，不只是怎么做
- [ ] 有「边界与反模式」章节
- [ ] 所有官方结论都有具体页面链接（非首页），并标注访问日期
- [ ] 个人经验结论已明确标注为「个人实测」
- [ ] 头部标注了适用版本与验证日期

## 可执行性
- [ ] 每条命令都在真机跑过
- [ ] 配置片段标明了文件路径
- [ ] 没有未说明的占位符
- [ ] 外部依赖标明了安装方式与版本

## 图
- [ ] 至少 1 张原创机制图（非装饰图）
- [ ] 源文件已入库（`.mmd` / `.excalidraw` / `.d2` / `.html` / `.tape`）
- [ ] 配色符合 `docs/02-visual-system.md` 的令牌，强调色 ≤ 3
- [ ] 亮色和暗色背景下都清晰
- [ ] 竖屏切片用的是**竖版专属图**，不是横图缩放（横图在手机上必然看不清）
- [ ] 每张图有描述性 `alt`
- [ ] 图的结论在正文中有文字复述
- [ ] 截图/GIF 无 token、无真实姓名路径、无内部仓库名

## 排版
- [ ] 中英文之间有空格
- [ ] 术语符合 `docs/03-writing-style.md` 的术语表
- [ ] 代码块都标了语言
- [ ] 无连续 5 段纯文字
- [ ] 所有相对链接可跳转

- [ ] 已更新 `docs/04-outline.md` 中该篇的状态
- [ ] 已想好 1 张切片图 + 3 条要点用于社媒分发
