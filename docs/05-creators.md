## 怎么挑（我们的入选标准）

| 标准 | 说明 |
| --- | --- |
| **有实操** | 屏幕上真的在敲命令、改代码，不是纯 PPT 念稿 |
| **讲机制** | 会解释「为什么这么做」，不只是「跟我做」 |
| **更新稳定** | 近 3 个月有更新，工具类内容过期极快 |
| **不纯带货** | 不是每期都在推同一个付费课/联盟链接 |
| **可验证** | 会给出仓库、配置、版本号 |

**主动避开**：标题党（「XX 已死」「震惊」）、纯 API key 教程、无源码的「我用 AI 做了个 App」。

## 核实流程（把 🔎 变成 ✅）

对上表每一位，做完以下 5 步再写进正式文章：

1. **搜索确认账号真实存在**，记录**准确的频道名 + URL + 平台内唯一 ID**（handle 会变，ID 不会）。
2. **看最近 3 条内容的发布时间** —— 超过 3 个月没更新的，移入「归档」。
3. **随机抽 1 期完整看完**，对照上面的「入选标准」打分。
4. **抽查 1 个技术结论**，回到 T1 官方文档验证是否属实。有明显错误且不更正的，直接剔除。

## 使用纪律

- 看视频**只用于找选题和发现工具**，不抄结论、不抄标题、不抄图。
- 如果某个观点确实来自某位创作者，在文章里**注明来源并给链接**，这是基本尊重也是可信度来源。
- 不做「XX 频道推荐」类的凑数文章 —— 这类内容对读者价值低，也不符合本专题定位。
