# 欧美 LangChain / LangGraph 教学资源调研

调研时间：2026-09。筛选标准只有一条——**能不能手把手跟着敲**。
纯讲概念、没有可运行代码仓库的，一律不收。

| --- | --- | --- | --- | --- | --- | --- |

## 为什么主线选官方 Academy

1. **代码就是课程本体。** `github.com/langchain-ai/langchain-academy` 里 30 个 notebook，
   每个开头都链回对应的视频课，看不懂就跑，跑不通就看。
2. **它跟着版本更新。** 该仓库最近一次更新在 2026 年 6 月，
   依赖已经是 `langchain-core>=1.2.28`、`langchain-openai>=1.1.14`，属于 v1 时代的写法。
   这一点其他免费资源基本都做不到。
3. **它带 LangGraph Studio。** 每个 module 有 `studio/` 子目录，
   `langgraph dev` 就能在浏览器里看图跑图、断点、改状态。这是理解「图」最快的方式。
4. **它一路带到部署。** Module 6 直接讲 LangGraph Platform 部署、Assistants、双发消息处理。

## 需要知道的版本坑

- **2025-10：LangChain 与 LangGraph 同时发到 1.0**，承诺到 2.0 之前不再破坏性变更。
- **`langgraph.prebuilt` 已废弃**，`create_react_agent` 这类能力搬到了 `langchain.agents`，
  现在的入口是 `from langchain.agents import create_agent`。
- 网上 2024 年写的 LangGraph 教程占多数，`from langgraph.prebuilt import create_react_agent`
  之类还能跑但已经不是推荐写法。**认准 1.x 的资料。**
- 官方文档站已改版到 `docs.langchain.com`，旧的 `langchain-ai.github.io/langgraph` 是历史版本。

## 分类结论：主线 / 补充 / 保持不落伍

**只有一条主线。多线并行学同一个框架，最后大概率每条都学到 30% 就散了。**

### 主线（走完这一条就够）

| 资源 | 为什么是它 |
| --- | --- |
| 官方 Academy《Introduction to LangGraph》Module 0–6 | 可运行仓库 + 跟着版本更新 + 带可视化调试台，这三点其他资源凑不齐 |

### 补充（和主线互补，不是竞争）

| 资源 | 补什么 | 什么时候用 |
| --- | --- | --- |
| **《Learning LangChain》**（O'Reilly，2025-02，296 页） | **课程教你敲，书告诉你为什么这样设计。** 作者之一是 LangChain 创始工程师，等于官方出品 | 主线学到一半时开始读，可回翻、可做标记 |
| DeepLearning.AI《AI Agents in LangGraph》（1.5 h） | 建立直觉。**第一节「从零手写 agent」的顺序是对的**——先知道框架替你做了什么 | 主线开始前当开胃菜 |
| freeCodeCamp《LangGraph Complete Course》（3 h 10 m） | 查漏。某个概念主线没讲透时换个人再听一遍 | 卡住时 |
| freeCodeCamp《Agentic AI using LangGraph》（约 24 h） | 项目驱动 + 部署实战（AWS／Render） | 主线学完后做作品集 |
| Academy《Ambient Agents》《Deep Research with LangGraph》 | 真项目 + 用 LangSmith 做评测 | 主线学完后的第一、第二个真项目 |

### 保持不落伍（不是教程，是订阅）

| 资源 | 作用 |
| --- | --- |
| **官方文档 `docs.langchain.com`** | 按使用场景组织，例子是生产级的，更新最快。**学到中后期，它的价值会超过任何课程** |
| LangChain 官方 YouTube 频道 | 发布会、新特性、真实案例拆解。作用不是学，是不落伍 |
| 官方博客的版本公告 | 1.0 之后承诺到 2.0 前不破坏性变更，但生态包仍在动 |

### 明确不推荐进主线

| 资源 | 原因 |
| --- | --- |
| Udemy 各类 LangChain 课程 | 口碑最好的那门（7 万+ 学生）确实细，但**付费且更新滞后**。真要买，先看最近更新日期，别买到 v0 时代的 |
| YouTube 零散播放列表 | 适合通勤当背景听，**不适合当主线**——没有配套仓库结构，跟着敲容易断 |
| 中文二手教程 | 多数停在 2024 年的 v0 写法，照抄跑不通 |

## 学习顺序建议

```
DeepLearning.AI 短课（1.5h，建立直觉）
        ↓
官方 Academy Module 0–3（核心，一定要动手）
        ↓
官方 Academy Module 4–6（进阶 + 部署）
        ↓
Ambient Agents 或 Deep Research 项目课（做出作品）
        ↓
freeCodeCamp 24h 项目课（查漏 + 部署实战）
```
