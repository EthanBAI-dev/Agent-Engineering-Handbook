## 四个台阶

| 台阶 | 讲次 | 读者获得的能力 |
| --- | --- | --- |
| 一、能跑起来 | 总纲 + 01–07 | 装好环境，写出会分叉的图，让它长出工具和记忆，跑成服务 |
| 二、能管住状态 | 08–13 | 控制状态的形状和合并方式，长对话不崩 |
| 三、能让人插手 | 14–18 | 看见过程，中途停下、改状态、回到过去重来 |
| 四、能拆能上线 | 19–30 | 并行、子图、扇出、多角色协作、长期记忆、部署 |

## 写作规范

本课程的写作由项目 skill 约束：

```
.claude/skills/langgraph-course-lesson/SKILL.md
```

**写任何一讲之前先读它，以及上面那份概念归属表。**

## 环境基线

Python 3.11–3.13，langgraph 1.2.x。**总纲和第 02 讲不需要任何钥匙，零成本。**
