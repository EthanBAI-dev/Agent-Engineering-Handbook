## 四个台阶

| 台阶 | 讲次 | 读者获得的能力 |
| --- | --- | --- |
| 一、能跑起来 | 00–08 | 装环境 → 会分叉的图 → 亲手写一遍循环 → 长出工具和记忆 → 跑成服务 |
| 二、能管住状态 | 09–14 | 控制状态的形状和合并方式，长对话不崩 |
| 三、能让人插手 | 15–19 | 看见过程，中途停下、改状态、回到过去重来 |
| 四、能拆能上线 | 20–31 | 并行、子图、扇出、多角色协作、长期记忆、部署 |

> **第 05 讲是编辑增补**：先不用框架手写一遍 agent 循环，撞上它的天花板，
> 第 06 讲再看框架版本时才知道框架替你做了什么。

## 写作规范

本课程的写作由项目 skill 约束：

```
.claude/skills/langgraph-course-lesson/SKILL.md
```

**写任何一讲之前先读它，以及上面那份概念归属表。**

## 环境基线

Python 3.11–3.13，langgraph 1.2.x。**第 00 讲和第 02 讲不需要任何钥匙，零成本。**
