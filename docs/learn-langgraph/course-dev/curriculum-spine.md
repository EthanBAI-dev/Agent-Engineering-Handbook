## 二、概念归属地图

**规则：一个概念只有一个「归属课」给完整定义。别的课只能预告或一句话回顾。**

| 概念 | 归属课 | 允许预告 | 允许回顾 | 禁止重复 |
| --- | --- | --- | --- | --- |
| 环境安装（Python / VS Code / 终端 / venv / pip） | **L0** | — | L1 一句话确认 `(.venv)` | ❌ L1 及以后不得再给安装命令 |
| 官方课程仓库环境 + 三个 Key | **L0**（末节「第二阶段环境」） | L1 Step 3 只给链接 | — | ❌ L1 不得再列 Key 表格 |
| State / Node / Edge | **L1** Step 1 | L0 用「格子和岔路」打比方 | L2 一句话 | ❌ |
| 条件边与路由函数 | **L1** Step 1 | — | L2 引出 ReAct 时回顾一句 | ❌ |
| reducer | **L1** Step 2 | — | L2 讲 `add_messages` 时回顾 | ❌ 完整定义只在 L1 |
| checkpointer / thread_id | **L1** Step 2 | — | L2 | ❌ |
| interrupt / 时间旅行 | **L1** Step 2 | — | 后续 M3 内容 | ❌ |
