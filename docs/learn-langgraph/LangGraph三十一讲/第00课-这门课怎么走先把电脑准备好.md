# 这门课怎么走，先把你的电脑准备好

> **导读：** 要让程序自己一步步把活干完，你得先有个能跑代码的电脑。
> 这一讲先说清楚这门课会带你走到哪、每一讲长什么样，
> 然后从「电脑上什么都没有」开始，装两个软件、跑通第一个程序。
> 读完你会有一个随时能开工的环境，和一句能对别人讲清楚的路线。

写给完全没写过代码的人。以 Windows 为主，Mac 在后面单说。

## 这门课要把你带到哪

一共 31 讲，分四个台阶，**每一个台阶都是在解决上一个台阶留下的麻烦**。

| 台阶 | 讲次 | 你会拿到什么 | 然后你会遇到的麻烦 |
| --- | --- | --- | --- |
| 一 | 01–08 | 让程序跟会聊天的 AI 说上话，画出一张会分岔的流程，再让它反复做直到做完 | 要记的东西一多就乱套 |
| 二 | 09–14 | 管住那份大家共用的数据，让很长的对话也不崩 | 它全自动跑起来了，你插不进手 |
| 三 | 15–19 | 看见它正在干什么，中途叫停、改掉、甚至退回去重来 | 一件事它一个人干不完 |
| 四 | 20–31 | 让几件事同时做、把大任务拆开、让几个角色分工，最后放到网上给别人用 | —— |

**每一讲的结尾都会明确交出一个没解决的问题，下一讲接着解决它。**
所以按顺序读最省力，跳着读会漏掉「为什么要有这个东西」。

## 你不需要具备什么

- **不需要写过代码。** 这门课假设你连命令行都没打开过。
- **不需要懂数学。** 全课没有公式。
- **不需要好电脑。** 普通笔记本就行，费力气的计算都在远端的机器上跑。
- **前两讲不花钱。** 从第 01 讲起才要花钱，跑完一整讲大概几分钱。

## 每一讲长什么样

固定四块：**先讲清一个概念 → 给一段能跑的代码 → 你自己动手改 → 交出下一讲要解决的问题。**

代码全在 `课程代码/lessons/` 里，一讲一个文件，**都是能直接跑的，不是片段**。

每个动手环节都有一条**验收标准**，比如「跑出来是 2」。
达不到就说明哪里错了，不用猜。

## 打个比方：灶台和厨房

写代码要两样东西。

**Python 是灶台**——真正把菜做熟的是它，但它自己没有台面，你看不见它。

**编辑器是厨房**——切菜的台面、放调料的架子、打火的开关，都在这儿。

你在厨房里干活，灶台在背后默默烧火。**所以两个都要装，缺一个都做不成饭。**

## 第一步 · 装 Python（10 分钟）

打开 <https://www.python.org/downloads/>，点那个大黄色按钮，下载下来双击。

### 装的时候有一个坑，只有一个

安装窗口的**最下面**，有一个小方框：

```
☐  Add python.exe to PATH
```

**必须勾上它，勾上再点 Install Now。**

不勾会怎样？黑框里打 `python` 会说「不是内部或外部命令」，然后你会卡住两个小时。

> 已经装完才发现没勾？重新运行那个安装包，选 `Modify`，一路下一步，
> 把 `Add Python to environment variables` 勾上就行。

**版本 3.11、3.12、3.13 都行**，官网默认给你的就在这个范围里。3.10 及以下不行。

## 第二步 · 装编辑器（5 分钟）

打开 <https://code.visualstudio.com/>，点 `Download for Windows`，一路下一步。

中间几个勾选项**建议全勾**，尤其这两个：

```
☑  将"通过 Code 打开"操作添加到 Windows 资源管理器文件上下文菜单
☑  添加到 PATH
```

勾上以后，任何文件夹右键就能直接用它打开。

### 装完先装两个插件

打开它，看**最左边那一竖条图标**，找到像四个方块的那个（快捷键 `Ctrl + Shift + X`）。
上面有搜索框，搜两次，各装一个：

| 搜什么 | 装哪个 | 干什么 |
| --- | --- | --- |
| `Chinese` | Chinese (Simplified) Language Pack | 把界面变成中文 |
| `Python` | Python（作者是 Microsoft，下载量最多的那个） | 让它认识 Python 代码 |

装完中文包会让你重启，重启就好。**这两个装完，厨房就搭好了。**

## 第三步 · 把课程代码拿到手（5 分钟）

不用装别的东西，浏览器打开这个链接就会自动下载：

<https://github.com/EthanBAI-dev/Agent-Engineering-Handbook/archive/refs/heads/claude/amazing-wozniak-rh6ryk.zip>

下载完解压，**建议放桌面或 `D:\code\` 这种简单路径**。

> **路径里千万别有中文和空格。** `D:\code\` 可以，
> `C:\Users\我的文档\新建文件夹 (2)\` 会出各种莫名其妙的错。这是最常踩的坑之一。

解压出来的文件夹右键 →「通过 Code 打开」。没有这个菜单就在编辑器里点
`文件` → `打开文件夹`。

打开后左边出现文件树，**顺着点进去：`docs` → `learn-langgraph` → `课程代码` → `lessons`**。
你会看到几个 `.py` 文件，点一下就能在右边看到代码。

## 第四步 · 找到那个「黑框」（3 分钟）

**这是你最需要知道的一件事。**

代码不是点一下就跑的，你得有个地方打命令。那个地方叫**终端**——
说白了就是一个只能打字、不能点的窗口，你打一行命令，它做一件事。

打开它：快捷键 `Ctrl` + `` ` ``（数字 1 左边、和 `~` 同一个键），
或者点菜单栏 `终端` → `新建终端`。

下半部分会弹出一个框，里面有一行字，末尾是 `>` 或 `$`。
**这就是终端，以后所有命令都打在这里，打完按回车。**

先验证 Python 装好了：

```
python --version
```

**看到 `Python 3.12.x` 之类就成了。** 看到「不是内部或外部命令」，回第一步补勾 PATH。

## 第五步 · 搭一个专用工作区（5 分钟）

先进到课程目录。`cd` 的意思是「进入某个文件夹」：

```
cd docs\learn-langgraph
```

打完回车，终端那行字会变长，末尾多了 `learn-langgraph`——**说明你现在「站」在这里了。**

然后建一个虚拟环境。**虚拟环境就是给这个项目单独开一个抽屉**，
装的东西都放这个抽屉里，不跟别的项目混：

```
python -m venv .venv
.venv\Scripts\activate
```

**成功的标志：终端那行字最前面多了一个 `(.venv)`。** 像这样：

```
(.venv) PS D:\code\Agent-Engineering-Handbook\docs\learn-langgraph>
```

不开抽屉也能跑，但几个项目一混就会打架，到时候更难查。

> **Windows 上可能报一个错**，说什么「禁止运行脚本」。打这一行再重试：
> ```
> Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
> ```

## 第六步 · 装 LangGraph（3 分钟）

**确认前面有 `(.venv)` 再打：**

```
pip install -U langgraph
```

`pip` 是负责下载安装的工具。会哗啦啦滚很多字，看到 `Successfully installed` 就好了。

验证：

```
python -c "from langgraph.graph import StateGraph; print('ok')"
```

**打印出 `ok`，环境就全部搞定了。**

## 第七步 · 跑通第一个程序（2 分钟）

```
python 课程代码\lessons\lesson02_simple_graph.py
```

关键的是这几行：

```
--- 走到 node_hello ---
--- 走到 node_happy ---
{'text': '我想开心一点 你好，今天很开心！'}

--- 走到 node_hello ---
--- 走到 node_sad ---
{'text': '随便说点什么 你好，今天有点累。'}
```

**同一个程序，跑了两次，走了两条不同的路。**

它做的事是：画了三个格子和一个岔路口，岔路口看文字里有没有「开心」两个字，
有就往左走，没有就往右走。**第 02 讲会把这件事讲透，现在跑通就行。**

### 不想打命令的话

打开那个 `.py` 文件，**右上角有一个三角形的播放按钮**，点它，效果一样。

第一次点会在最上面弹出一个条让你选，**选带 `.venv` 字样的那一个**。选错了会说找不到 LangGraph。

## 后面才会用到的钥匙

**第 00、02 讲不用钥匙，从第 01 讲开始才要。** 现在可以先跳过这一节。

要让代码调用大模型，你得有一把钥匙——**就是一串字符，
用来证明这次是你在调用，好按你的账号算钱。**

本课程默认用 DeepSeek——**它就是一个会聊天的大模型，跟 ChatGPT 是同一类东西**，
国内可直连、便宜、后面讲的每个能力它都能跑。

| 钥匙 | 干什么 | 什么时候要 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | 调大模型，课程的发动机 | 第 01 讲起 |
| `TAVILY_API_KEY` | 让程序能上网找资料 | 台阶四才用 |
| `LANGSMITH_API_KEY` | 看清每一步到底调了什么，调试全靠它 | 可选，有免费额度 |

去 platform.deepseek.com 申请第一个，然后：

```
pip install -U langchain-deepseek
```

**把钥匙告诉程序，用环境变量，别写进代码文件。** 环境变量就是设给这个终端窗口的一个值：

```
$env:DEEPSEEK_API_KEY = "你的钥匙"        # Windows
export DEEPSEEK_API_KEY="你的钥匙"        # Mac
```

**关掉终端就失效，下次要重新设。** 想一劳永逸就设成系统环境变量。

验证：

```
python -c "import os; print('有钥匙' if os.environ.get('DEEPSEEK_API_KEY') else '没读到')"
```

> **钥匙等于钱。** 别贴进代码、别提交到网上、别发在聊天框里。

### 想换成别的模型

全课只有一行跟模型厂商有关：

```python
from langchain_deepseek import ChatDeepSeek        # DeepSeek
model = ChatDeepSeek(model="deepseek-chat")

from langchain_openai import ChatOpenAI            # 换成 OpenAI 就这两行
model = ChatOpenAI(model="gpt-4o")
```

**其余代码一个字都不用改。** 后面每一讲都保持这个性质。

## 报错速查表

存下这张表，90% 的问题在这儿。

| 屏幕上说 | 真实原因 | 怎么办 |
| --- | --- | --- |
| `python 不是内部或外部命令` | 装 Python 时没勾 PATH | 重跑安装包选 Modify，补勾 |
| `ModuleNotFoundError: langgraph` | 忘了激活虚拟环境 | 看前面有没有 `(.venv)` |
| `禁止运行脚本` | Windows 默认拦截 | `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process` |
| `系统找不到指定的路径` | `cd` 到错的地方了 | 打 `dir` 看当前有什么，对不上就 `cd ..` 退回去 |
| 点播放按钮说找不到 LangGraph | 编辑器选错了 | `Ctrl+Shift+P` → 搜「Python: 选择解释器」→ 选带 `.venv` 的 |
| 一堆看不懂的红字 | 路径里有中文或空格 | 把文件夹挪到纯英文路径 |

## 每次开始前，固定做三个动作

1. 打开编辑器，`文件` → `打开最近的文件夹`，选这个项目
2. `Ctrl` + `` ` `` 打开终端
3. 打 `.venv\Scripts\activate`，确认看到 `(.venv)`

**看到 `(.venv)` 才能开始。十次报错有六次是忘了这一步。**

## 用 Mac 或公司电脑怎么办

**Mac** 只有三处不一样，其余完全相同：

| 事情 | Windows | Mac |
| --- | --- | --- |
| 建抽屉 | `python -m venv .venv` | `python3 -m venv .venv` |
| 激活 | `.venv\Scripts\activate` | `source .venv/bin/activate` |
| 路径斜杠 | `课程代码\lessons\xxx.py` | `课程代码/lessons/xxx.py` |

Mac 自带的 Python 版本通常太老，去官网下新的。

**公司电脑装不了软件**，就用浏览器版的：在这个项目的网页上点
`Code` → `Codespaces` → 新建，它给你一个云端编辑器，环境全都有，免费额度够学。

## 这一讲得到了什么，下一讲接着讲什么

你的电脑现在能跑代码了：**Python 是灶台，编辑器是厨房，终端是你说话的地方，
虚拟环境是这个项目专用的抽屉。** 你还跑通了第一个程序，看到同一段代码走出了两条路。

你也知道了这门课的走法：四个台阶，每一阶解决上一阶留下的麻烦。

但到目前为止，**你跑的那个程序里根本没有大模型**——它只是按写死的规则在分岔。

下一讲就把那个会聊天的 AI——也就是大模型，ChatGPT、DeepSeek 那类——接进来：
**代码怎么跟它说上第一句话，
回来的东西长什么样，以及一件很多人想不到的事——它记不住你上一句说了什么。**
