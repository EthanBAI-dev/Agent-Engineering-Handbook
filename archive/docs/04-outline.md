## 母实验 A · 用 AI 复刻网站并上线（M1，第一个做）

**为什么先做这个**：结果是一个能打开的网页，最直观；失败的版本天然就是好素材；
同时覆盖支柱 ① 和 ②。

### 实验设计

```
输入：一张真实网站截图（用公开的、允许参考的站点，见风险说明）
过程：喂给 AI → 生成 → 迭代 → 部署到 Vercel
记录：每一轮的截图、耗时、花费、失败原因
输出：一个能公开访问的网址
```

### 派生的 7 条内容

| # | 类型 | 档位 | 标题 | 素材来源 | 状态 |
| --- | --- | --- | --- | --- | --- |
| A1 | 短 | 流量 | AI 做的网站为什么一眼就很廉价？问题不在模型 | 第一版失败截图 | ⬜ |
| A2 | 短 | 流量 | 让 AI 复刻网页，这一步 90% 的人漏了 | 喂设计参考的那一步 | ⬜ |
| A3 | 短 | 流量 | 三个 AI 复刻同一张截图，差距有多大 | 并列结果对比 | ⬜ |
| A4 | 短 | 流量 | 2 小时，从一张截图到上线 | 成品 + 计时 | ⬜ |
| A5 | 中 | 信任 | 完整教程：截图 → 可部署网站（含失败过程） | 全程录屏 | ⬜ |
| A6 | 深 | 权威 | 网站复刻的边界：版权风险、技术路线、改造方法 | 调研 + 判断 | ⬜ |
| A7 | 连载 | 信任 | 项目第 1 周：做了什么、卡在哪 | 过程记录 | ⬜ |

### ⚠️ 风险提示（A6 必须正面讲）

**复刻他人网站有版权风险。** 这不是可以回避的技术细节，是这个选题的核心。

- 演示**只用**明确允许参考的站点、开源模板，或自己的旧站
- 视频和文章里**明确说明**：复刻用于学习，商用需自行设计或取得授权
- A6 这一篇专门讲清楚边界——**这反而是差异化**，别人不敢讲

### 拍摄与记录清单

- [ ] 每一轮生成后立刻截图存档（**失败的也要**）
- [ ] 计时器全程开着，记录每一步耗时
- [ ] 记录 token 花费
- [ ] 终端操作用 VHS 或 OBS 录（设置见 [`06-video-workflow.md`](06-video-workflow.md) §3）
- [ ] 演示仓库 + 演示账号，不用真实项目

## 母实验 B · 三个工具做同一个需求（M2）

**需求要选得刚好**：太简单看不出差距，太复杂做不完。
建议：一个带表单提交和数据存储的落地页，2 小时内单个工具能做完。

### 派生的 7 条内容

| # | 类型 | 档位 | 标题 | 状态 |
| --- | --- | --- | --- | --- |
| B1 | 短 | 流量 | 同样做一个网站，Codex 和 Claude Code 谁更强？ | ⬜ |
| B2 | 短 | 流量 | 三个 AI 工具，只有一个想到了这件事 | ⬜ |
| B3 | 短 | 流量 | 同一个任务，费用差了 4 倍 | ⬜ |
| B4 | 短 | 流量 | Codex 和 Claude Code 适合的人完全不同 | ⬜ |
| B5 | 中 | 信任 | 完整横评：同一需求，三个工具的全过程 | ⬜ |
| B6 | 深 | 权威 | Codex / Claude Code / Cursor 的设计取向与使用边界 | ⬜ |
| B7 | 连载 | 信任 | 横评过程中翻车的三个瞬间 | ⬜ |

### 横评强制项（见 [`00-plan.md`](00-plan.md) §6 第 3 条）

- [ ] 标题或开头写死**测试日期 + 各工具版本号**
- [ ] 三个工具用**完全相同的提示词**，提示词全文公开
- [ ] 记录耗时、花费、失败次数
- [ ] **展示失败过程**，不只放成品
- [ ] 结论给明确的购买建议，不和稀泥
- [ ] 加入季度复检清单

## 母实验 C · 接上数据库，做一个能注册登录的应用（M2）

**这是「玩具」和「产品」的分界线。** 大多数 AI 建站教程止步于静态页面，
一碰到用户系统和数据库就没了。这里正好是空档。

技术栈建议：Next.js + Supabase + Vercel（都有免费额度，读者能跟着做）。

### 派生的 7 条内容

| # | 类型 | 档位 | 标题 | 状态 |
| --- | --- | --- | --- | --- |
| C1 | 短 | 流量 | AI 做的网站能存数据吗？能，但有个前提 | ⬜ |
| C2 | 短 | 流量 | 登录功能让 AI 做，最容易出的安全问题 | ⬜ |
| C3 | 短 | 流量 | 给 Claude Code 接上数据库，它就变了个样 | ⬜ |
| C4 | 短 | 流量 | 免费额度能撑多少用户？我算了一下 | ⬜ |
| C5 | 中 | 信任 | 完整教程：从零到一个能注册登录的应用 | ⬜ |
| C6 | 深 | 权威 | 让 AI 碰数据库和密钥，权限该怎么管 | ⬜ |
| C7 | 连载 | 信任 | 这周踩的坑：环境变量、迁移、和一次差点泄露的密钥 | ⬜ |

> C2 和 C6 涉及安全，**必须自己验证过再写**。
> 写错了会害人，这类内容不能靠推测。
